# osis-bridge-cantilever-box

> 模板在 `references/templates/`,命中就复制(流程见 `osis-engine` §模板优先策略)。本文件写三件事:怎么选模板和改模板、本桥型的方案默认值、钢束怎么分类和优化。API 写法在各 `osis-module-*`。

## 必问参数

| 参数 | 选项(第一项为推荐) | 何时问 |
|---|---|---|
| 跨径组合 | 模板清单里的跨径,最接近用户需求的排第一 | 没提跨径 |
| 桥宽 | 所选模板的桥宽(看它的项目画像)、其他 | 模板里没有同宽 |
| 截面形式 | `单箱单室`、`单箱双室` | 主跨 > 80m;≤ 60m 默认单箱单室 |
| 主梁材料 | `C55`、`C50` | 没提材料 |
| 节段对数(每 T 构) | 模板默认 | 没提节段方案 |
| 桥墩形式 | `双柱墩`、`单柱墩` | 主跨 > 60m;≤ 50m 默认双柱 |

钢束分组、张拉参数不主动问,用户指定才改。

## 模板

模板清单现场列:`ls references/templates/`,目录名里写着跨径组合。清单会更新,不要凭记忆报有哪些模板。

按**跨径组合**匹配。模板里没有用户要的截面形式(如单箱双室)时先告诉用户,再用最接近跨径的模板改截面。

| 情况 | 做法 |
|---|---|
| 跨径、桥宽、截面形式都一致 | 复制后直接跑 |
| 只是跨径不同 | 选**每 T 构节段对数相同**的最近模板,跑 `spanremap`(见下) |
| 只改跨中梁高 | `osis-edit-hmid` |
| 桥宽、根部梁高、板厚不同 | 改 `_4_section.py`,再重算构件理论厚度写回 `_6`(`osis-module-element` §构件理论厚度) |
| 材料不同 | 只改 `_3_material.py` |

**不要等比例缩放截面和钢束。** 截面保持模板原样,只挪节点;钢束只在跨中直线段增减长度,曲线段(起弯点、半径、过渡段)不变。

### 改跨径:`spanremap`

三跨悬浇只改跨径时用脚本,不要手改 `_5` / `_2` 的数字:

```bash
python "<skill_dir>/scripts/spanremap.py" --to "<目标跨径>"
```

- 只动节点 x 和钢束曲线 x,`_6`~`_10` 不变。
- 边跨的变化量只进现浇段里最靠近合龙段的一个等截面单元:端部加厚段、渐变段、支座位置不动,不加节点。这个单元缩不到 0.3m 以下,边跨要缩短较多时脚本会拒绝,换边跨更接近的模板。
- 中跨的变化量进合龙段两侧的恒高段;合龙段保持 2m,T 构整体平移。
- 看 stdout 的校核(节点数、梁端、墩位、合龙 2m、单调/总长/镜像、钢束曲线全部改到、钢束圆弧放得下)。
- 校核失败、不是三跨、或节段对数不同:换模板;找不到同节段对数的模板就停下来告诉用户,不要手搓钢束。

## 截面方案

变截面:跨中恒高段 + 边跨现浇段 + 悬浇渐变段 + 0 号块;桥墩是独立的矩形截面。

梁高只在**变化段**用抛物线,与构造评分 D3 同一套坐标(详见 `references/section_parabola.md`):

`h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n`

- `x`:距 **0 号块外缘**的距离。0 号块内 `h = h_root`;合龙段和跨中平台 `h = h_mid`。
- `L`:变化段长度 = 半主跨 − 合龙段半长 − 0 号块半宽(**不是**距墩中心,也不是半主跨 − 合龙段半长)。
- `n`:按主跨取,**不要默认 2**。改 n 要按桩号重算各截面 h,不要从旧高度开方反推。

| 主跨 | n |
|---|---|
| [50, 100) m | 1.8 或 2.0 |
| [100, 150] m | 1.8 |
| (150, 200] m | 1.5 |

梁高经验值:

| 主跨 L | 根部 h_root | 跨中 h_mid |
|---|---|---|
| 30~50m | L/15 ~ L/18 | L/28 ~ L/35 |
| 60~80m | L/16 ~ L/18 | L/30 ~ L/38 |
| 80~120m | L/17 ~ L/20 | L/35 ~ L/45 |
| 120~200m | L/18 ~ L/22 | L/38 ~ L/50 |

## 节段方案

| 项 | 取值 |

## 其余方案默认值

以复制来的模板为准;从零写或用户没给时用下表。

| 项 | 默认 |
|---|---|
| 材料 | 主梁 C50~C55;桥墩 C45~C50;钢绞线 Strand1860;临时束用精轧螺纹钢 Rebar785 |
| 节点 | 主梁节点落在节段端点、0 号块边界、合龙段端点、钢束锚固点(距梁端约 0.15m),不等距 |
| 单元组 | 每个节段一组(`0号块单元`、`1号块单元`…)、边跨/中跨合龙段、边跨现浇段、桥墩弹簧;车道参照组 `主梁单元` |
| 钢束投影组 | 每根钢束一组,`<钢束名>Gp` 或 `<钢束名>_CurveGp`,以模板为准 |
| 永久支座 | 每个墩台两组(一侧横向固定、一侧横向放开);一个中墩纵向固定,其余墩台纵向放开 |
| 临时约束 | 悬浇期间墩梁临时锚固;边跨现浇段临时支架 |
| 荷载 | 主梁、桥墩、合龙段各自的自重工况;二期 = 铺装 + 护栏;沉降:桥墩 15mm、桥台 10mm |

## 施工阶段

```
CS1        下部及 0 号段(28d)
CS2~       1~N 号段,每段三个阶段:挂篮 1d → 浇筑 8d → 张拉 1d
之后       边跨支架现浇(12d)
           边跨合龙(12d)  ★ 体系转换:激活永久支座和桥墩弹簧,钝化临时支架
           中跨合龙(12d)  钝化 1 号墩的临时纵向约束
           二期恒载(60d)
           徐变十年(3650d)
           运营阶段(0d)
```

阶段数随节段对数变,具体编号看项目画像。

## 钢束

| 类别 | 含义 |
|---|---|
| T | 顶板束(悬臂束),每个节段张拉一对 |
| F | 腹板束(悬臂束、下弯),每个节段张拉一对 |
| ZB / ZT | 中跨底板束 / 中跨顶板束,中跨合龙后张拉 |
| BB / BT | 边跨底板束 / 边跨顶板束,边跨合龙后张拉 |

- 每类条数随节段对数变,以模板为准。
- **每个阶段块一个预应力工况**(如 `0号块预应力`),`_8` 创建、`_10` 按名引用。
- 底板束(BB、ZB)是贴底束,改动前先读 `osis-module-tendon` §贴底束 bottom() 机制。
- 边跨底板束:名字带 `-z` 的锚在左梁端、带 `-y` 的锚在右梁端,锚点距梁端 0.15~0.20m;两侧不要写成同一段 x。

### 钢束优化

流程见 `osis-check/references/tendon_optimize.md`,本节给悬浇连续梁的分区和控制指标。

**分区**(按画像的墩位、0 号块、合龙段取 x 范围,左右对称取较不利一侧):墩顶(0 号块及 1~2 号块)、中跨跨中(合龙段及两侧最后 3~4 对节段)、边跨跨中、边跨端部(现浇段到梁端)。

| 类别 | 作用 | 每束加 1 根的主要影响 | 减根数时必须看 |
|---|---|---|---|
| T 顶板束 | 悬臂束,平衡悬浇负弯矩 | 墩顶上缘压应力增、下缘减;锚在外侧节段的束使中跨跨中上缘压应力增 | 最大悬臂阶段(最后一对节段张拉后、合龙前)墩顶上缘拉应力;运营墩顶上缘储备 |
| F 腹板束 | 悬臂束,下弯,兼抗剪 | 墩顶附近上缘压应力增;腹板主拉应力降;在外侧节段作用接近顶板束,中跨跨中上缘压应力增 | 同 T;腹板斜截面抗裂、主压应力、抗剪 |
| ZB 中跨底板束 | 合龙后张拉,中跨正弯矩 | 中跨跨中下缘压应力增;二次弯矩影响墩顶 | 跨中下缘储备;**徐变后跨中下挠**(减 ZB 下挠增大) |
| ZT 中跨顶板束 | 合龙段上缘 | 中跨跨中上缘压应力增 | 跨中上缘储备 |
| BB 边跨底板束 | 边跨正弯矩 | 边跨跨中下缘压应力增 | 边跨下缘储备、压限余量 |
| BT 边跨顶板束 | 边跨上缘 | 边跨上缘压应力增 | 边跨上缘储备 |

- T、F 每个节段张拉一对,束数跟节段对数绑定:只改根数,不删束
- 模板里不同类常共用一个规格(如 T 与 BB、F 与 ZB),单改一类先拆规格(`osis-module-tendon` §改每束根数)
- 大跨悬浇的通病是跨中长期下挠。方案只要动了 ZB、BB,就要给出徐变十年阶段跨中挠度的前后对比。挠度取累计值,不要拿本阶段增量
- 中跨跨中使用阶段压应力超限通常在**上缘**(悬臂束、ZT、温度梯度、二期都压上缘);读出来是下缘超限,先回头核对应力点上下缘再往下做
- 中跨跨中**上缘**压应力超限:主要减外侧节段 T、F 和 ZT 的根数,减 ZB 基本没用。65+118+65 实测单元拆分,上缘压应力里 T+F+ZT 约占 51%,ZB 不到 5%,温度梯度约 18%(钢束管不到)。减外侧节段 T、F 同时会削弱墩顶,复核时看最大悬臂阶段墩顶上缘、墩顶运营储备
- 估算只算本区;合龙束(ZB、BB)对墩顶的二次弯矩不计,复核一轮再看
