# osis-bridge-cantilever-box

> 章节顺序与 `_0`~`_10` 模块对齐,按"截面 → 节点 → 单元 → 边界 → 荷载 → 钢束 → 活载 → 阶段"顺序对应写 `prep/_N.py`。

## 必问参数 (question 工具)

用户提示缺这些参数时,打包成一个 question 调用一次问完。**options 第一项(推荐默认)锚定模板库:给用户说的参数找最接近的模板,推荐该模板的参数组合并标注「有现成模板可直接复制,最快」**;用户自报值保留为次选项(走复制+小修)。选定模板参数 → 后续 §直接复制优先 路径,求快闭环(osis-engine §会话硬约束 · 默认求快)。

| 参数 | 选项(第一项为推荐) | 何时可省 |
|---|---|---|
| 跨径组合(主跨 L) | 模板库现有 `30+50+30` / `35+60+35` / `40+70+40` / `42+75+42` / `45+80+45` / `50+90+50` / `55+100+55` / `60+110+60` / `62.5+115+62.5` / `65+120+65` / `70+130+70` / `76+140+76` / `80+150+80`;用户跨径接近某模板时推荐该项 | 用户没提跨径时必问 |
| 桥宽 | `12.75m`(全部模板同此值)、`16.75m`、`其他` | 模板里没有等宽时必问 |
| 截面形式 | `单箱单室`(全部模板同此)、`单箱双室` | 跨径 ≤ 60m 默认真单箱单室;>80m 必问 |
| 主梁材料 | `C55`、`C50` | 没提材料时必问 |
| 节段对数(每 T 构) | 模板默认(主跨 30~50m 取 5~6,50~80m 取 6~8,80~150m 取 8~12) | 没提节段方案时问 |
| 桥墩形式 | `双柱墩`、`单柱墩` | 跨径 ≤ 50m 默认真双柱;>60m 必问 |

> 钢束分组(6 类 BB/BT/F/T/ZB/ZT)、张拉参数用本 SKILL §钢束 默认值,**不主动问**;用户明确指定才覆盖。

## 截面 (→ prep/_4_section.py, osis-module-section)

### 截面方案

- 单箱单室或单箱双室,以单箱单室为主
- 变截面:跨中恒高段 + 边跨现浇段 + 桥墩 + 悬浇渐变段 + 0 号块
- 梁高只在**变化段**用抛物线,与构造评分 D3 同一套坐标(详见 `references/section_parabola.md`):
  `h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n`
  - `x`:距 **0 号块外缘**。0 号块内 `h = h_root`;合龙/跨中平台 `h = h_mid`
  - `L`:变化段长度 = 半主跨 − 合龙段半长 − 0 号块半宽(**不是**距墩中心,也不是半主跨 − 合龙半长)
  - `n`:按主跨取,见下表;**不要默认 2**。改 n 必须按桩号重算 h,禁止从旧高度开方反推指数

| 主跨 | 取 n |
|---|---|
| [50, 70) m | 1.8 或 2.0 |
| [70, 100) m | 1.8 或 2.0 |
| [100, 150] m | 1.8 |
| (150, 200] m | 1.5 |

- 梁高经验值:

| 主跨 L | 桥墩 h_root | 跨中 h_mid |
|---|---|---|
| 30~50m | L/15 ~ L/18 | L/28 ~ L/35 |
| 60~80m | L/16 ~ L/18 | L/30 ~ L/38 |
| 80~120m | L/17 ~ L/20 | L/35 ~ L/45 |
| 120~200m | L/18 ~ L/22 | L/38 ~ L/50 |

- 截面数量 ≈ 跨中恒高段(1) + 桥墩(1,独立 rect) + 边跨现浇段(1) + 悬浇渐变段(N=节段对数) + 0 号块(2~3)

### 节段方案

- 每个 T 构节段对数:主跨 30~50m 取 5~6 对,50~80m 取 6~8 对,80~150m 取 8~12 对
- 节段长度:3.5~5m,从跨中向 0 号块渐变
- 0 号块长度:桥墩中心两侧各 2~4m
- 合龙段长度:典型 2m

### 桥墩/桥台

- 双柱墩(主梁两侧 ±2.8m 偏置)或单柱墩(主梁底 z 偏置)
- 桥台:锚固端,桥台节点 z 偏置

## 节点 (→ prep/_5_node.py, osis-module-node)

主梁节点沿 y=0、z=0 轴线,按**节段端点 + 锚固点 + 0 号块边界 + 合龙段端点**布置,不等距:

- 0 号块边界(桥墩中心 ±2m)
- 各节段端点(每个节段 2 个)
- 锚固点(钢束端部 ~0.15m)
- 合龙段端点(中跨跨中 ±2m)

桥墩节点:双柱墩 y 偏置 ±2.8m,z = -h(主梁底)。

## 单元 (→ prep/_6_element.py, osis-module-element)

### 构件组(语义)

- **节段组**:每个节段独立成组(0号块/1号块/2号块/.../N号块)
- **合龙段组**:边跨合龙段 + 中跨合龙段
- **现浇段组**:边跨支架现浇段(如有)
- **桥墩弹簧组**:每个桥墩弹簧成组

### 钢束投影组

按"钢束名 + CurveGp/Gp"约定,**组名格式由 `osis-module-element` 定义**,本 SKILL 不规定具体名字。

### 车道引用组

`主梁单元`:包含全部主梁单元,供 `_9_analysis` 引用车道。

### 构件理论厚度

规则权威源:`osis-module-element` §分配构件理论厚度(本系列模板已用改前已知厚度校验过)。摘要:

- **截面**:`h_sec = 2A / (u_outer + u_in/2)`(箱梁;不是 `u_outer+u_in`)
- **单元**:`h_elem = (h(nSec1)+h(nSec2))/2`,再按相同 `h_elem` 分批 `assign_component_thickness`
- **取数**:`engine.section.get(no).contour` 鞋带公式算 A/周长;`prop` 常为 `None`,不要空等接口
- **改梁高/板厚/桥宽必重算**;悬浇渐变段各节段 `h_elem` 不同是正常的
- 改跨径但截面方案不变(§模板适配最小 diff 规程)时,厚度值可直接复用

## 边界 (→ prep/_7_boundary.py, osis-module-boundary)

### 支座方案

| 部位 | 永久支座 | 临时约束 |
|---|---|---|
| 1 号桥墩(中墩) | 横固纵释 + 横释纵释 两组 | 0 号块施工时**墩梁临时锚固** |
| 2 号桥墩(中墩) | 横固纵固 + 横释纵固 两组 | 同上 |
| 桥台 1/2 | 横固纵释 + 横释纵释 两组 | 无 |
| 边跨 | — | **边跨临时支架**(支架现浇段施工时激活) |

### 体系转换时序

- **CSxx 边跨合龙阶段**(关键节点):
  - 激活:4 组永久支座(横固/横释/纵固/纵释)× 2 桥台 + 4 组桥墩弹簧
  - 钝化:4 组临时支架(2 桥墩 + 2 边跨)
- **CSxx+1 中跨合龙阶段**:
  - 激活:中跨合龙段
  - 钝化:桥墩 1 临时纵向约束(合龙后释放)

具体阶段编号因跨径/节段方案不同而不同,以项目画像为准。

## 荷载 (→ prep/_8_loadcase.py, osis-module-loadcase)

### 自重与二期

- **自重**:主梁/桥墩/合龙段 单独自重工况
- **二期恒载**:铺装(左右半幅) + 防撞护栏(左右)

### 温度

- 整体升温 +20℃、整体降温 -20℃(所有单元)
- 正温度梯度、负温度梯度(按规范 T 型)

### 沉降

- 桥墩:15mm
- 桥台:10mm

## 钢束 (→ prep/_8_loadcase.py, osis-module-tendon)

### 分组(6 类)

| 类别 | 含义 | 典型数量(40+70+40 单箱单室) |
|---|---|---|
| BB(Bottom Bar) | 边跨底板束 | 10 条(BB4~BB8,各 y/z) |
| BT(Beam Top) | 边跨顶板束 | 12 条(BT3~BT8,各 y/z) |
| F(F-loop) | 跨中腹板束 | 18 条(F0~F8,各 1/2) |
| T(Top) | 跨中顶板束 | 18 条(T0~T8,各 1/2) |
| ZB(Zhong Bottom) | 中跨底板束 | 6 条(ZB3~ZB8) |
| ZT(Zhong Top) | 中跨顶板束 | 5 条(ZT3~ZT7) |

具体命名格式(`BB{y/z}Gp` vs `BB{y/z}_CurveGp`)由 `osis-module-tendon` 决定。

### 张拉方案

- **两端张拉**(`tension_type="BOTH"`)
- **张拉控制应力**:1.395e9 Pa(1395MPa,典型 0.75 × 1860MPa)
- **控制方式**:`tension_force_type="ST"`(力控制)

### 钢束约束

- 控制点 x 必须在 element_group 覆盖范围内
- 钢束张拉阶段晚于构件激活阶段
- 跨中合龙前,中跨钢束未张拉;边跨合龙前,边跨钢束未张拉
- **预应力工况名是 `_8` 与 `_10` 的契约**:每个阶段块的预应力工况(如 `0号块预应力`)在 `_8` 的 `load.create(<名>, "CS", ...)` 创建,`_10` 的 `define_loadcase(..., <名>)` 逐字引用,不得改写;钢束 shape 名(`F0-1` 等)只出现在 `_8` 的 `create("PST", ...)` 里,不出现在 `_10`

### 边跨底板束端部定位

- 左边跨底板束**起点**距梁端 **0.15~0.20 m**
- 右边跨底板束**终点**距梁端 **0.15~0.20 m**

## 活载 (→ prep/_9_analysis.py, osis-module-analysis)

- **移动荷载标准**:`JTGD60_2015,HIGHWAY_I`
- **车道**:3 个工况(左偏 / 中载 / 右偏),车道长度取中跨满跨
- **横向折减系数**(固定):`[1.2, 1.0, 0.78, 0.67, 0.6, 0.55, 0.52, 0.5, 0.5, 0.5]`
- **冲击系数 μ**:跨径/梁型相关,数值看项目画像(1.05~2.50)
- **沉降**:桥墩 + 桥台

## 施工阶段 (→ prep/_10_stage.py, osis-module-stage)

### 施工方法

- 0 号块:支架现浇
- 1~N 号块:挂篮悬浇,每节段"挂篮 → 浇筑 → 张拉"三步
- 边跨合龙段:支架现浇
- 中跨合龙段:吊架合龙
- 阶段数随跨径增大而增多:30+50+30 约 23 阶段,80+150+80 约 65 阶段

### 阶段序列轮廓

```
CS1       下部及 0 号段(28d)
CS2~CSxn  1~N 号段 × (挂篮 1d + 浇筑 8d + 张拉 1d)
CSxn+1    边跨支架现浇(12d)
CSxn+2    边跨合龙(12d) ★ 体系转换
CSxn+3    中跨合龙(12d) [如有体系转换则再加]
CSxn+4    二期恒载(60d)
CSxn+5    徐变十年(3650d)
CSxn+6    运营阶段(0d)
```

### 阶段时长模板

- 0 号段:28d
- 每个悬浇节段:挂 1d + 浇 8d + 张 1d = 10d
- 边跨合龙:12d
- 中跨合龙:12d
- 二期:60d
- 徐变:3650d(10 年)
- 运营:0d

### 体系转换要点

悬浇连续梁(非刚构)从简支悬浇状态转换为连续体系,关键节点为边跨合龙阶段:
- 激活永久支座和桥墩弹簧
- 钝化临时支架和墩梁临时锚固

具体步骤看 `references/templates/` 项目画像。

## 模板与代码生成

### 模板位置与布局

目录树、builder 名、入口见总控 `osis-engine/references/template_layout.md`。本桥模板在 `references/templates/`(平铺)。

### 模板枚举(接到本桥型建桥任务第一件事)

1. `ls references/templates/`(平铺子目录;本库**没有**刚构 `变截面连续刚构-*`)
2. **向用户显式报告** `共 N 个模板: [完整目录名, ...]`。名单像被截断 → 再 ls
3. **禁止**未列出全量就宣布「最近模板是 xxx」
4. 用户说「悬浇连续刚构」→ 停,改走 `osis-bridge-rigid-frame-box`,不要在本库里找 108+200

### 匹配规则

按**截面形式(单箱单室 / 单箱双室) → 跨径**两级匹配。覆盖两种截面形式,等截面与变截面处理方式不同。**仅当全量清单里没有同跨径组合时**才用最接近跨径。

### 直接复制优先(模板命中时的默认路径)

总控 §模板优先策略 在本桥型的落地。**命中模板时不要自行构思,直接复制是最快且最稳的路径**:

- **精确命中**(跨径组合 + 桥宽 + 截面形式与某模板一致):**按总控 §模板优先策略复制**(WeKnora 优先,失效再 `seedtpl`);`项目画像.md` 一并落地,字段已填好,核对一遍即可
- **近似命中**:先直接复制,再只改差异处(详见 §模板适配最小 diff 规程):
  - 跨径差一档 **且节段对数相同** → 跑 `spanremap --to <目标跨径>`,禁止手改 `_5`/`_2` 数字;`_6`~`_10` 零改动
  - 跨径差一档但**节段对数不同**(画像「每 T 构 N 对」不一致,如 13 对 vs 16 对)→ 换同节段对数的近邻再跑 `spanremap`
  - **只改跨中梁高** → 走 `osis-edit-hmid`(5 分钟路径,不重算钢束/`_6`)
  - 桥宽/根部梁高/板厚不同 → 改 `_4_section.py`,并按 §构件理论厚度重算各单元 `h_elem` 写回 `_6`
  - 材料不同 → 只改 `_3_material.py`
- 复制路径**不逐项执行 §必问参数**:模板内嵌参数即默认值,完工报告列出假设清单请用户确认

**变截面梁** 与普通悬浇梁方案完全相同,仅多"变截面"标签。

**变截面刚构**(刚构桥型,如 `变截面连续刚构-*`)由 `osis-bridge-rigid-frame-box` 覆盖,不在本 SKILL 范围。

### 跨径 fallback 规则

**仅当 §模板枚举 的全量清单里没有同跨径组合时**才允许采用跨径最接近的模板作为基础。未报全量不得 fallback。近邻必须**节段对数相同**;不同则再找下一座同构模板,找不到就停下来告诉用户,不要手搓钢束。**严禁**对截面、预应力钢束采用等比例缩放。截面保持原模板不变,仅调整节点位置;钢束应从跨中直线段截去相应长度减短,曲线段(起弯点、半径、过渡段)几何不变。

### 模板适配最小 diff 规程(改跨径/桥宽时)

**前置**:源模板与目标的「每 T 构节段对数」必须相同。不同则换同构近邻,不要手搓钢束。

悬浇三跨只改跨径 → 调本 SKILL 的 `scripts/spanremap.py`,禁止手改 `_5`/`_2` 数字(脚本只动节点 x 和钢束曲线 x,`_6`~`_10` 零改动;边跨 ΔL 进现浇段,中跨 ΔL 进合龙两侧恒高段,合龙 2m 与 T 构刚体平移):

```bash
python "<skill_dir>/scripts/spanremap.py" --to "<目标跨径>"
```

看 stdout 校核(节点数、梁端、墩位、合龙 2m、单调/总长/镜像)。失败或非三跨 → 换近邻,不要手改。桥宽/h_root/板厚仍改 `_4`(必要时 `_6` 的 `h_elem`);只改 h_mid 走 `osis-edit-hmid`。贴底束 bottom 机制见 `osis-module-tendon`。
