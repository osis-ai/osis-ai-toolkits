# 悬浇连续梁变截面梁高推算

## 梁高公式

抛物线**只作用在变化段**。0 号块平台 `h = h_root` 不变,合龙段/跨中平台 `h = h_mid` 不变。

```
h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n
```

| 符号 | 含义 | 常见错法(禁止) |
|---|---|---|
| `x` | 距 **0 号块外缘** 的距离(变化段起点为 0) | 距桥墩中心 |
| `L` | **变化段长度** = 半主跨 − 合龙段半长 − 0 号块半宽 | 半主跨 − 合龙段半长(把 0 号块算进抛物线) |
| `n` | 按下表按主跨选取,与构造评分 D3 一致 | 一律写 2 |

评分器拟合 D3 时用同一套坐标:`u = (L - x) / L`,`u = 1` 在 0 号块外缘。x 从墩中心起算时,拟合 n 会系统性偏低(例如按 1.6 建、评成 1.4)。

## n 怎么取(悬浇连续梁)

| 主跨 | 取 n | 模板 |
|---|---|---|
| [50, 70) m | 1.8 或 2.0 | 50m 用 1.8,60m 用 2.0 |
| [70, 100) m | 1.8 或 2.0 | 70m 用 1.8,80m 用 2.0 |
| [100, 150] m | **1.8** | 90~150m 模板均为 1.8 |
| (150, 200] m | **1.5** | — |

**不要默认 n=2。** 改 n 时按各节段桩号用上式**重算 h**。禁止从旧截面高度用平方根(或 `1/n_old`)反推 `(1-x/L)` 再改指数——旧高度若不是你以为的那一次,新曲线会变成错误幂次。

只改 `h_mid`、n 与桩号不变时,走 `osis-edit-hmid` 的比例换元,不必重算 x。

## 桥墩/跨中梁高经验值

| 主跨 L | 桥墩梁高 h_root | 跨中梁高 h_mid |
|---|---|---|
| 30~50m | L/15 ~ L/18 | L/28 ~ L/35 |
| 60~80m | L/16 ~ L/18 | L/30 ~ L/38 |
| 80~120m | L/17 ~ L/20 | L/35 ~ L/45 |

**主跨越大,深跨比越小**(从 ~1/15 渐变到 ~1/20)。

## 节段数量与长度

| 主跨 | 推荐节段数(每 T 构) | 节段长 |
|---|---|---|
| 30~50m | 5~6 对 | 3.5~4m |
| 50~80m | 6~8 对 | 3.5~4.5m |
| 80~150m | 8~12 对 | 4~5m |

## 实战算例:30+50+30 悬浇梁(与模板一致)

- 总长 110m,跨径 30+50+30
- 半主跨 25m,0 号块半宽 1.5m,合龙段半长 1m
- **L = 25 − 1 − 1.5 = 22.5m**(变化段长度)
- h_root = 3.2m,h_mid = 2.2m,**n = 1.8**

`x` 从 0 号块外缘起;下表 `s` 为距墩中心,`x = s − 1.5`。

| 位置 | s 距墩中心 (m) | x 距 0 号块外缘 (m) | h (m) |
|---|---:|---:|---:|
| 0 号块内 | 0.0~1.5 | (平台) | 3.200 |
| 0 号块外缘 | 1.5 | 0.0 | 3.200 |
| 近墩节段 | 2.5 | 1.0 | 3.121 |
| | 5.5 | 4.0 | 2.903 |
| | 9.0 | 7.5 | 2.682 |
| | 12.5 | 11.0 | 2.499 |
| | 16.0 | 14.5 | 2.356 |
| 近跨中 | 20.0 | 18.5 | 2.245 |
| 跨中平台起点 | 24.0 | 22.5 | 2.200 |

验算(x=1.0):`h = 2.2 + 1.0 * (1 - 1/22.5)^1.8 = 3.121`。

若误用「x 距墩中心、L=23、n=2」,0 号块外缘就会被算成低于 `h_root`,评分器拟合 n 也会偏离 1.8。

## 截面编号编排建议

```
sec1   跨中等高段(h = h_mid)
sec2   桥墩(rect,独立)
sec3   边跨现浇段(h = h_mid,加厚腹板/底板)
sec4~sec4+N-1    悬浇段(跨中→墩,按上式 h(x) 递增)
sec4+N           0 号块外缘(h = h_root)
sec4+N+1~sec4+N+M  0 号块中心(h = h_root,腹板/底板最厚)
```

N = 节段对数;M = 0 号块截面分段数(通常 2~3)。

## 改梁高的连锁改动

改 `h` 必须联动改 `tb`(顶板厚)、`tw`(腹板厚)、`bb`(底板宽)等依赖参数,否则 `该参数组合几何检查不通过`。从目标 h 反推全部几何参数,不要只改一处。
