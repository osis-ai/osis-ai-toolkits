## 1. 项目定位

- 桥型:变截面悬浇连续梁(三跨)
- 体系:三跨连续梁(墩顶活动支座,设体系转换)
- 跨径:40 + 70 + 40m,总长 150m
- 桥宽:12.75m
- 单片梁宽:6.375m(单箱单室,顶宽)
- 主梁材料:C55
- 桥墩材料:未单独建(无 C45/RECT,仅支座与临时支架)
- 截面形式:单箱单室
- 节段对数:每 T 构 8 对节段 + 3 个 0 号截面
- 合龙段:边跨 + 中跨 1 个

## 2. 材料

- 主梁混凝土:C55
- 桥墩混凝土:未单独建
- 普通钢筋:HRB400
- 钢绞线:Strand1860
- 精轧螺纹钢(临时束):Rebar785
- 收缩徐变:avg_humidity=75%, birth_time=7d, type_coeff=5.0, shrink_birth=3

## 3. 截面

- 类型:单箱单室变截面(主梁)(无独立 RECT 桥墩截面)
- 截面数量:13 个(跨中 1 + 边跨现浇 1 + 悬浇渐变 8 + 0 号段 3)
- 梁高:
  - 跨中 h_mid:2.2m
  - 桥墩 h_root:4.5m
  - 公式:`h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n`,n=1.8
  - x:距 0 号块外缘(变化段起点);0 号块内 h=h_root;合龙/跨中平台 h=h_mid
  - L:变化段长度 = 半主跨 − 合龙段半长 − 0 号块半宽
- 顶板宽:6.375m,底板宽:4.225m
- 腹板厚:
  - 跨中标准段:0.50m
  - 悬浇渐变段:0.5~0.75m
  - 桥墩附近(0 号段):0.75~1m
  - 边跨现浇段:0.75m
- 顶板厚:跨中 0.26m,根部 0.42m
- 底板厚:跨中 0.25m,根部 0.8m
- 悬臂长度:2.15m(顶宽-底宽,两侧)
- 网格尺寸:0.1m

- 节点:67 个

  - 弹簧单元_桥墩 1_顶底 / 弹簧单元_桥墩 2_顶底
  - 主梁单元
