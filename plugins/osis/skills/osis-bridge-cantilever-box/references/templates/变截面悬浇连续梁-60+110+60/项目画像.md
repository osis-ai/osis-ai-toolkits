# 变截面悬浇连续梁-60+110+60

> 本文件由AI维护,记录本桥项目特定参数。通用建模规则按 `osis-bridge-cantilever-box` 执行。
> 来源:evaluate/修改梁高-材料底板厚 (2026-08 按 prep 回填)。

---

## 1. 项目定位

- 桥型:变截面悬浇连续梁(三跨)
- 体系:三跨连续梁(墩顶活动支座,设体系转换)
- 跨径:60 + 110 + 60m,总长 230m
- 桥宽:12.75m
- 单片梁宽:6.375m(单箱单室,顶宽)
- 主梁材料:C55
- 桥墩材料:未单独建(无 C45/RECT,仅支座与临时支架)
- 截面形式:单箱单室
- 节段对数:每 T 构 13 对节段 + 3 个 0 号截面
- 合龙段:边跨 + 中跨 1 个

## 2. 材料

- 主梁混凝土:C55
- 桥墩混凝土:未单独建
- 普通钢筋:HRB400
- 钢绞线:Strand1860
- 精轧螺纹钢(临时束):Rebar785
- 收缩徐变:avg_humidity=75%, birth_time=7d, type_coeff=5.0, shrink_birth=3

## 3. 截面

- 类型:单箱单室变截面(主梁)(无独立 RECT 桥墩截面)
- 截面数量:18 个(跨中 1 + 边跨现浇 1 + 悬浇渐变 13 + 0 号段 3)
- 梁高:
  - 跨中 h_mid:3.0m
  - 桥墩 h_root:6.8m
  - 公式:`h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n`,n=1.8
  - x:距 0 号块外缘(变化段起点);0 号块内 h=h_root;合龙/跨中平台 h=h_mid
  - L:变化段长度 = 半主跨 − 合龙段半长 − 0 号块半宽
- 顶板宽:6.375m,底板宽:4.225m
- 腹板厚:
  - 跨中标准段:0.50m
  - 悬浇渐变段:0.5~0.75m
  - 桥墩附近(0 号段):0.75~1m
  - 边跨现浇段:0.75m
- 顶板厚:跨中 0.26m,根部 0.515m
- 底板厚:跨中 0.25m,根部 1.1m
- 悬臂长度:2.15m(顶宽-底宽,两侧)
- 网格尺寸:0.1m

## 4. 节点与单元

- 节点:87 个
- 总单元数:86
- 单元组:
  - 0 号块单元(每 T 构)
  - 1~13 号块单元(每 T 构 13 对)
  - 边跨现浇段
  - 左边跨合龙段 / 右边跨合龙段
  - 中跨 1 合龙段 / 中跨合龙段
  - 弹簧单元_桥台 1_顶底 / 弹簧单元_桥台 2_顶底
  - 弹簧单元_桥墩 1_顶底 / 弹簧单元_桥墩 2_顶底
  - 主梁单元

## 5. 边界体系

- 桥墩支座(CS44 激活,体系转换阶段)
- 桥台支座(CS42 激活,边跨合龙阶段)
- 桥墩临时支架:边跨合龙前激活,体系转换时钝化
- 边跨临时支架:边跨施工时激活,边跨合龙时钝化
- 桥台沉降组:桥台 1、桥台 2 各 12mm;桥墩 1、桥墩 2 各 15mm

## 6. 钢束

- 张拉控制应力:1.395e9 Pa(两端张拉)
- 共 113 束(命名去重),分 6 类:
  - BB(边跨底板):18 束,BB10-y ~ BB9-z
  - BT(边跨顶板):20 束,BT10-y ~ BT9-z
  - F(跨中腹板):28 束,F0-1 ~ F9-2
  - T(跨中顶板):28 束,T0-1 ~ T9-2
  - ZB(中跨底板):10 束,ZB10-1 ~ ZB9-1
  - ZT(中跨顶板):9 束,ZT10-1 ~ ZT9-1

## 7. 荷载

- 自重:各节段、合龙段单独自重工况
- 二期恒载:铺装(左右半幅) + 防撞护栏(左右)
- 沉降:桥墩 1、桥墩 2 各 15mm;桥台 1、桥台 2 各 12mm
- 温度:整体升降温 + 正负温度梯度

## 8. 活载分析

- 车道数:左偏 / 中载 / 右偏(共 3 个工况)
- 车道长度:110m(中跨满跨加载)
- 冲击系数:μ=1.4(CUSTOM)

## 9. 施工阶段

| 阶段 | 名称 | 时长 | 主要动作 |
|---|---|---:|---|
| CS1 | 0 号段施工 | 28d | 激活 0 号块、桥墩临时支架、0 号块自重、预应力 |
| CS2~CS40 | 1~13 号段 × (挂 1d + 浇 8d + 张 1d) | 各 10d | 挂篮激活/钝化、湿重激活/钝化、节段激活、张拉预应力 |
| CS41 | 边跨支架现浇 | 12d | 激活边跨现浇段、左/右边跨临时支架、边跨合龙湿重、吊架荷载 |
| CS42 | 边跨合龙 | 12d | 激活桥台永久支座、弹簧单元、左/右合龙段、预应力;钝化临时支架 |
| CS43 | 中跨 1 合龙 | 12d | 激活中跨合龙段、张拉中跨预应力 |
| CS44 | 体系转换 | 15d | 激活桥墩永久支座、桥墩弹簧;钝化桥墩临时支架 |
| CS45 | 二期恒载 | 60d | 激活铺装、防撞护栏 |
| CS46 | 徐变十年 | 3650d | 长期效应 |
| CS47 | 运营阶段 | 0d | 激活温度、沉降、活载分析(左偏/中载/右偏) |
