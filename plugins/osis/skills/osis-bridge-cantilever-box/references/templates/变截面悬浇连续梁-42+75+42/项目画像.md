# 变截面悬浇连续梁-42+75+42

> 本文件由AI维护,记录本桥项目特定参数。通用建模规则按 `osis-bridge-cantilever-box` 执行。

---

## 1. 项目定位

- 桥型:变截面悬浇连续梁(三跨)
- 体系:三跨连续梁(墩顶活动支座,设体系转换)
- 跨径:42 + 75 + 42m,总长 158.349m
- 桥宽:12.75m
- 单片梁宽:6.375m(单箱单室,顶宽)
- 主梁材料:C55
- 桥墩材料:C45(单肢矩形墩)
- 截面形式:单箱单室
- 节段对数:每 T 构 8 对节段 + 1 个 0 号段
- 合龙段:边跨 + 中跨 1 个

## 2. 材料

- 主梁混凝土:C55
- 桥墩混凝土:C45
- 普通钢筋:HRB400
- 钢绞线:Strand1860
- 精轧螺纹钢(临时束):Rebar785
- 收缩徐变:avg_humidity=75%, birth_time=7d, type_coeff=5.0, shrink_birth=3

## 3. 截面

- 类型:单箱单室变截面(主梁) + 矩形桥墩
- 截面数量:13 个(跨中 1 + 桥墩 1 + 边跨现浇 1 + 悬浇渐变 8 + 0 号段 2)
- 梁高:
  - 跨中 h_mid:2.4m(L/31)
  - 桥墩 h_root:6.0m(L/12.5)
  - 公式:`h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n`,n=1.8
  - x:距 0 号块外缘(变化段起点);0 号块内 h=h_root;合龙/跨中平台 h=h_mid
  - L:变化段长度 = 半主跨 − 合龙段半长 − 0 号块半宽
- 桥墩矩形:2.5m × 7m(单肢)
- 顶板宽:6.375m,底板宽:6.375m
- 腹板厚:跨中标准段 0.50m,桥墩 0.50m

## 4. 节点与单元

- 节点:65 个,x 终点 158.349m
- 单元:64 个 beam3d
- 单元组:`0号块单元`、`1~8号块单元`、`合龙段单元`(边跨 + 中跨)、`边跨现浇段单元`、`桥墩单元`、`主梁单元`

## 5. 边界体系

- 1 号桥墩(中墩):横固纵释 + 横释纵释 两组(全约束 + 释放 X)
- 2 号桥墩(中墩):横固纵固 + 横释纵固 两组(全约束 + 释放 X)
- 桥台 1/2:横固纵释 + 横释纵释 两组
- 边跨:**边跨临时支架**(支架现浇段施工时激活)
- CS27 边跨合龙 + CS28 中跨合龙 + CS29 体系转换:激活永久支座,钝化临时支架和墩梁临时锚固

## 6. 钢束

- 张拉控制应力:1.395e9 Pa(两端张拉,ST)
- 规格:15-5 / 15-7 等
- 66 束,6 类(每束配 y/z 镜像):
  - BB(边跨底板束):BB4~BB8 × 2 = 10 束
  - BT(边跨顶板束):BT3~BT8 × 2 = 12 束
  - F(跨中腹板束):F0~F8 × 2 = 18 束
  - T(跨中顶板束):T0~T8 × 2 = 18 束
  - ZB(中跨底板束):ZB3~ZB8 = 6 束
  - ZT(中跨顶板束):ZT3~ZT7 = 5 束
- 孔道参数:μ=0.17, k=0.0015/m, 锚具变形 6mm/6mm, 松弛 0.3
- 边跨底板束(BB)起/终点距梁端 0.2m

## 7. 荷载

- 自重:0号块~8号块 各自重工况, g = -9.8066 m/s²
- 端横梁:节点集中力(数值和节点号看项目画像)
- 二期恒载:铺装 + 防撞护栏(左右半幅)
- 温度:整体升降温 ±20℃;正负温度梯度

## 8. 活载分析

- 移动荷载标准:`JTGD60_2015,HIGHWAY_I`
- 车道:3 个工况(左偏 / 中载 / 右偏),车道长度取中跨满跨
- 横向折减系数(固定):`[1.2, 1.0, 0.78, 0.67, 0.6, 0.55, 0.52, 0.5, 0.5, 0.5]`
- 冲击系数 μ:跨径/梁型相关,数值看项目画像
- 沉降:桥墩 15mm,桥台 10mm

## 9. 施工阶段

阶段数 32(8 节段对 + 收尾)。轮廓:

```
CS1       下部及 0 号段(28d)
CS2~CS25  1~8 号段 × (挂篮 1d + 浇筑 8d + 张拉 1d)
CS26      边跨支架现浇(12d)
CS27      边跨合龙(12d) ★ 体系转换
CS28      中跨合龙(12d)
CS29      体系转换(15d) ★ 关键
CS30      二期恒载(60d)
CS31      徐变十年(3650d)

```

- 中跨合龙:12d

- 二期:60d
