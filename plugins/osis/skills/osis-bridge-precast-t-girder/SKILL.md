# osis-bridge-precast-t-girder

> 章节顺序与 `_0`~`_10` 模块对齐,按"截面 → 节点 → 单元 → 边界 → 荷载 → 钢束 → 活载 → 阶段"顺序对应写 `prep/_N.py`。

## 必问参数 (question 工具)

| 参数 | 选项(第一项为推荐) | 何时可省 |
|---|---|---|
| 跨径(单跨 L) | `13m`、`16m`(仅预制简支)、`20m`、`25m`、`30m`、`35m`、`40m` | 没提跨径时必问 |
| 体系 | `先简支后连续`、`预制简支` | 没说"连续"时默认预制简支;想做连续必问 |

> 桥宽、横梁数等横向参数由项目给定(单梁模型不直接体现,通过二期恒载/横隔板间接反映)。

## 截面 (→ prep/_4_section.py, osis-module-section)

### 截面方案

T 梁:**标准截面 + 墩顶加厚截面 + 过渡段截面**(简支变连续才有后两者)。中梁与边梁区分:**中梁两侧有翼缘,边梁外侧翼缘长**。

### 跨径分档(梁高 / 腹板 / 钢束)

| 跨径 | 典型梁高 | 标准段腹板厚 | 钢束数(正弯矩/跨) |
|---|---|---|---|
| 20m | 1.5m | 0.18~0.20m | 3~4 束 |
| 25m | 1.7m | 0.20m | 4 束 |
| 30m | 2.0m | 0.20m | 4~5 束 |
| 35m | 2.3m | 0.20~0.22m | 5~6 束 |
| 40m | 2.5m | 0.22m | 6~7 束 |

> 上表是"默认规律",本项目实际参数以项目画像为准。**梁高严格按跨径选**,不缩放。

### T 梁截面 API

```python
sec = engine.section.create_TGirder(
    no,                            # 截面编号
    name="跨中",                   # 截面名
    girder_pos="Middle",           # "Left"/"Middle"/"Right"(中梁/边梁)
    h=1.5,                         # 梁高(m)
    bs=1.125,                      # 边翼板宽(m)
    bm=0.875,                      # 中梁半宽(m)
    bc=0.0,                        # 现浇湿接缝半宽(m)
    tt1=0.20,                      # 翼板厚(m)
    tt2=0.25,                      # 翼板根部厚(m)
    x=0.6,                         # 翼板倒角宽(m)
    tw=0.20,                       # 腹板厚(m)
    bh=0.6,                        # 马蹄宽(m)
    hh=0.35,                       # 马蹄高(m)
    yh=0.25,                       # 马蹄倒角高(m)
    slope=False,                   # 是否输入横坡
    i1=0.0, i2=0.0,                # 横坡参数(slope=True 时填)
    r=0.05,                        # 顶板倒角半径
)
```

**通用入口** `section.create(no, name, "TGIRDER", ...)` 关系同其他模块:只多一个 `type` 路由参数。

### 体系差异

| 维度 | 预制简支 | 简支变连续(先简支后连续) |
|---|---|---|
| 中墩顶构件 | 无 | 现浇段(湿接缝) |
| 钢束分组 | 仅正弯矩束 | 正弯矩束 + 负弯矩束 |

## 节点 (→ prep/_5_node.py, osis-module-node)

每跨内节点按**锚固段加密 + 标准段均布 + 墩顶加密**三段:

- **锚固段**:从梁端 ~0.08m 起,经 0.58m、0.88m 三点加密(锚固点位置,对应钢束端部)
- **跨中标准段**:1~2m 间距
- **墩顶加密**(简支变连续时):0.2~0.5m 间距,覆盖湿接缝范围

多跨时按"上一跨终点 + 本跨偏移"累加。跨数:1 跨(纯简支)、3~5 跨(简支变连续)。

### 改跨径时怎么改节点(近似命中必做)

与小箱梁同一方法:从已复制的 `_5` 认梁端锚固簇(及简支变连续的墩顶簇),当刚体;**逐跨**把 `Δ` 只送进该跨标准段。不要用固定米数切,不要改最右节点凑梁长,不要整桥缩放。`L_new` 保留模板梁端边距。`_6` 的 `sec1/sec2` 不动;`_2` 跨中直线段截 `Δ`,簇内控制点跟节点走。

写完自检:本跨左右加密簇镜像、无过短碎单元、两端加腋对称。不对称 = 从梁端砍了,按上面重做。

## 单元 (→ prep/_6_element.py, osis-module-element)

### 构件组(语义)

| 体系 | 需要的构件组 |
|---|---|
| 预制简支 | `预制单元`(每跨 1 个) + `主梁单元`(车道引用) |
| 简支变连续 | `预制单元`(每跨 1 个) + `现浇单元`(中墩顶湿接缝) + `主梁单元`(车道引用) |

### 钢束投影组

按 `钢束-{seq}-{tendon_name}线型单元` 命名,`seq` 是 1~N 全局序号。

### 车道引用组

`主梁单元`:包含全部主梁单元,供 `_9_analysis` 引用车道。

## 边界 (→ prep/_7_boundary.py, osis-module-boundary)

### 桥墩/桥台表达

- 桥台:锚固端,通过 boundary 表达,不显式建墩柱节点
- 中墩(简支变连续时):通过支座表达,体系转换时切换临时/永久支座

### 支座方案

| 部位 | 永久支座 | 临时约束 |
|---|---|---|
| 桥台 1(左) | 预制简支:x 向固定;简支变连续:x 向滑动 | — |
| 桥台 2(右) | x 向滑动 | — |
| 中墩(简支变连续) | 简支阶段:临时支座;体系转换后:永久支座 | 简支阶段激活 |

简支阶段激活 2 组临时支座;体系转换时激活 4 组永久支座(桥墩固定/滑动、桥台滑动 ×2),钝化临时支座。

### 体系转换时序(仅简支变连续)

- **CS3 墩顶现浇段施工**:激活现浇单元 + 激活负弯矩束(临时支座仍在)
- **CS4 体系转换**(关键节点):激活 4 组永久支座 + 钝化临时支座

## 荷载 (→ prep/_8_loadcase.py, osis-module-loadcase)

### 自重与二期

- **自重**:主梁/预制/现浇 自重工况,`create("GRAVITY", 0, 0, -1.04)`:-1.04 是乘 g 的系数(负=向下,1.04 计入钢筋等超重)
- **二期恒载**:铺装工况 + 防撞护栏工况(线荷载值看项目画像)
- **端横梁/横隔板**:节点集中力或线荷载(数值看项目画像)

### 温度

- 整体升温 +20℃、整体降温 -20℃(所有单元)
- 正温度梯度、负温度梯度(按规范 T 型)

## 钢束 (→ prep/_8_loadcase.py, osis-module-tendon)

### 分组(2 类)

| 类别 | 含义 | 位置 |
|---|---|---|
| 正弯矩束 | 跨内底板(马蹄内) | 每跨 3~7 束,规格 15-N |
| 负弯矩束 | 中墩顶翼缘 | 每中墩 2~4 束(仅简支变连续) |

具体命名(`N1`/`N2`/.../`T1`/`T2` 等)由本项目决定。规格 `15-N` 按束力选。

### 张拉方案

- **两端张拉**(`tension_type="BOTH"`),`tension_force_type="ST"`(力控制)
- **张拉控制应力**:1.395e9 Pa(1395MPa,典型 0.75 × 1860MPa)
- **孔道参数**:μ=0.17, k=0.0015/m, 锚具变形 6mm/6mm, 松弛 0.3

### 预应力荷载工况

- `预应力腹板束`(CS1):正弯矩束
- `预应力顶板束`(CS3):负弯矩束(简支变连续才有)

> 这两个名字是 `_8` 的 `engine.load.create(<名>, "CS", ...)` 与 `_10` 的 `define_loadcase(..., <名>)` 之间的**契约名**,两处必须逐字一致,不得同义改写。钢束 shape 名(`N1-1`/`T2-1` 等)只出现在 `_8` 的 `create("PST", ...)` 里,**不出现在 `_10`**。

### 钢束约束

- 钢束控制点 x 必须在 element_group(预制单元或现浇单元)覆盖范围内
- 钢束张拉阶段必须晚于对应构件激活阶段
- 负弯矩束只在墩顶湿接缝施工后(CS3)张拉

## 活载 (→ prep/_9_analysis.py, osis-module-analysis)

- **移动荷载标准**:`JTGD60_2015,HIGHWAY_I`
- **车道**:1 条(中线),车道长度取略小于跨径(单跨加载,避开锚固点)
- **横向折减系数**(固定):`[1.2, 1.0, 0.78, 0.67, 0.6, 0.55, 0.52, 0.5, 0.5, 0.5]`
- **冲击系数 μ**:跨径/梁型相关,数值看项目画像

## 施工阶段 (→ prep/_10_stage.py, osis-module-stage)

### 施工方法

预制厂预制主梁 → 存梁 → 架设到桥位(临时支座) → 浇筑墩顶湿接缝(简支变连续) → 张拉负弯矩束 → 体系转换 → 桥面铺装等二期恒载 → 长期徐变 → 运营

### 阶段序列轮廓

**预制简支(5 阶段)**:

```
CS1  主梁预制、张拉正弯矩束(7d)
CS2  存梁(60d)
CS3  二期恒载(30d)
CS4  徐变十年(3650d)
CS5  运营阶段(0d)
```

**简支变连续(7 阶段)**:

```
CS1  主梁预制、张拉正弯矩束(7d)
CS2  存梁(60d)
CS3  墩顶现浇段施工、张拉负弯矩束(7d)
CS4  体系转换(10d) ★ 关键
CS5  二期恒载(30d)
CS6  徐变十年(3650d)
CS7  运营阶段(0d)
```

## 模板与代码生成

### 模板位置与布局

目录树、builder 名、入口见总控 `osis-engine/references/template_layout.md`。本桥模板在 `references/templates/`(平铺)。

### 模板枚举(接到本桥型建桥任务第一件事)

1. `ls references/templates/`(平铺;`简支变连续-*` 与 `预制简支-*` 都在这一层)
2. **向用户显式报告** `共 N 个模板: [完整目录名, ...]`。名单像被截断 → 再 ls
3. **禁止**未列出全量就宣布「最近模板是 xxx」

### 匹配规则

在报出全量之后,按**体系(简支/简支变连续) → 中/边梁 → 跨径**三级匹配。**仅当全量清单里没有同跨径+梁位时**才用最接近跨径。

### 模板 fallback 规则

跨径不匹配时(**须已 ls 报全量且清单无同跨径+梁位**),用跨径最接近的模板。截面几何保持原模板(梁高按分档表)。节点按 §节点 改跨径时怎么改节点;钢束从跨中直线段截 `Δ`,冻结簇内跟节点走。

## 失败模式

- **右端碎单元 / 两端加腋不对称** —— 把最右节点改成目标梁长或整桥缩放。按 §节点 改跨径时怎么改节点 重做
