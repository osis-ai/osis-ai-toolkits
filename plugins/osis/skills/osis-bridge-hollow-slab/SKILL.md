# osis-bridge-hollow-slab

> 模板在 `references/templates/`,命中就复制(流程见 `osis-engine` §模板优先策略)。本文件写怎么选模板和改模板、本桥型的方案默认值和契约名。API 写法在各 `osis-module-*`。

## 必问参数

| 参数 | 选项(第一项为推荐) | 何时问 |
|---|---|---|
| 跨径(单跨) | 模板清单里的跨径,最接近用户需求的排第一 | 没提跨径 |
| 梁位 | `中梁`、`边梁` | 没提梁位(模板按梁位分) |
| 体系 | `预制简支`、`先简支后连续` | 用户想做连续时;没说"连续"默认预制简支 |

桥宽、板数不单独问:单梁模型里它们只体现在二期恒载和横向分布系数上。

## 模板

模板清单现场列:`ls references/templates/`,目录名里写着体系、跨径、梁位。清单会更新,不要凭记忆报有哪些模板。

按**体系 → 梁位 → 跨径**匹配。没有同跨径的才用最接近的跨径,然后按下面的规程改。

**清单里没有先简支后连续的模板时**:告诉用户后,用预制简支模板做底,墩顶现浇段、负弯矩束、临时/永久支座和体系转换阶段参照 `osis-bridge-precast-small-box` 的简支变连续方案补上。

### 改跨径时怎么改节点

只动**跨中均布段**的 x。不要按"梁端 + 标准段"整跨等比例重划(锚固点会错位,一端挤出碎单元),不要改最右节点去凑梁长。

- 从复制来的 `_5` 认梁端加密簇(间距密的那几个点,不要用固定米数切),当刚体:左簇不动,右簇随新梁端平移;跨长变化量 `Δ` 只进跨中均布段。目标跨长保留模板的梁端边距。
- `_6` 的截面号不动。
- `_2` 里钢束跨中直线段截去 `Δ`,簇里的控制点跟节点走。
- 梁高按下表换档,不按跨径比例算。

自检:左右加密簇关于跨中镜像;没有过短的碎单元;两端轮廓对称。

## 方案默认值

以复制来的模板为准;从零写或用户没给时用下表。

| 跨径 | 梁高 | 单片板宽 |
|---|---|---|
| 10m | 0.65m | 1.0m |
| 13m | 0.75m | 1.0m |
| 16m | 0.95m | 1.0m |
| 20m | 约 1.2m | 1.0m |
| 25m | 约 1.45m | 1.0m |

| 项 | 默认 |
|---|---|
| 材料 | 主梁 C40~C50;钢绞线 Strand1860 |
| 截面 | `HOLLOWSLAB`,标准截面 + 墩顶截面 + 加厚截面;中梁梁位 `"Middle"`、`set_offset("Middle", 0.0, "Top", 0.0)`;边梁梁位 `"Left"`,y 偏移不是 0,复制时连同 `set_offset` 一起保留 |
| 节点 | 梁端锚固点附近加密 + 跨中约 2m 均布 |
| 单元组 | `主梁单元`(阶段激活和车道参照都用它)、`封端混凝土单元` |
| 钢束投影组 | `钢束-{序号}-{钢束名}线型单元` |
| 支座 | 两组:`桥台1_永久_x向固定`(约束向量 `1,1,1,1,0,1,0`)、`桥台2_永久_x向滑动`(`0,1,1,1,0,1,0`),CS1 起激活 |
| 荷载工况 | `主梁单元自重`、`封端混凝土工况`、`预应力`、`铺装工况`、`防撞护栏工况`、`整体升温` / `整体降温`、`正温度梯度` / `负温度梯度` |
| 活载 | 1 条车道,长度略小于跨径;**横向分布系数**填进活载子工况的 `scalar`,取模板或项目画像的值,不要用 1.0;冲击系数用 `CUSTOM` + 基频 |
| 激活龄期 | `birth` = 7d |

## 钢束

正弯矩束 `N1`、`N2` 共 2 束,全部挂在预应力工况 `预应力` 上,CS1 与主梁预制同阶段张拉。工况名在 `_8` 创建、`_10` 引用,逐字一致。

## 施工阶段

```
CS1  主梁预制、张拉预应力(7d)   激活主梁单元、两组支座、自重、封端混凝土、预应力
CS2  存梁(60d)
CS3  二期恒载(30d)
CS4  徐变十年(3650d)
CS5  运营阶段(0d)              温度工况、活载、沉降
```
