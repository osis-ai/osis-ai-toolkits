# osis-bridge-hollow-slab

> 章节顺序与 `_0`~`_10` 模块对齐,按"截面 → 节点 → 单元 → 边界 → 荷载 → 钢束 → 活载 → 阶段"顺序对应写 `prep/_N.py`。

## 必问参数 (question 工具)

| 参数 | 选项(第一项为推荐) | 何时可省 |
|---|---|---|
| 跨径(单跨 L) | `10m`、`13m`、`16m`、`20m`、`25m` | 没提跨径时必问(实测样本只有 10/13/16m,**20m/25m 走 fallback**) |
| 体系 | `预制简支`、`先简支后连续` | 没说"连续"时默认预制简支;想做连续必问(本 skill **当前无变连续模板**,只能按预制简支脚本走,预应力体系按"只正弯矩束"处理) |
| 梁位 | `中梁`、`边梁` | 模板按梁位区分,必问 |

> 桥宽、横梁数等横向参数由项目给定(单梁模型不直接体现,通过二期恒载/横隔板间接反映)。

| 部位 | 推荐 | 规范 |

## 截面 (→ prep/_4_section.py, osis-module-section)

### 截面方案

空心板:**标准截面 + 墩顶加厚截面 + 过渡段截面** 共 3 个。**中梁 `e_girder_pos=Middle`,边梁 `e_girder_pos=Left` 且带 `SectionOffset`**(向下偏置以匹配外侧翼缘)。

边梁 vs 中梁的区别:
- 中梁:两侧翼缘等长,`SectionOffset=0,Top` 或不设
- 边梁:外侧翼缘长(设置 `SectionOffset` 让顶面对齐 0.0m 标高)

### 跨径分档(梁高 / 单片梁宽)

经验区间由 `osis-auto-testconformance` 评分器的 `_SIMPLE_H_OVER_L["hollow_slab"] = (1/24, 1/16)` 给出,实测样本如下:

| 跨径 | 典型梁高 | 单片梁宽 | 跨中 H/L | 说明 |
|---|---|---|---|---|
| 6m | ~0.45m | 1.0m | ≈1/13 | 经验下限附近 |
| 10m | 0.65m | 1.0m | ≈1/15.4 | **实测**:略超经验上界,设计规范允许 |
| 13m | 0.75m | 1.0m | ≈1/17.3 | **实测**:标准段 |
| 16m | 0.95m | 1.0m | ≈1/16.8 | **实测**:标准段 |
| 20m | ~1.20m | 1.0m | ≈1/16.7 | 接近经验上界,需复核 |
| 25m | ~1.45m | 1.0m | ≈1/17.2 | 经验区间下限,需复核 |

> **10m 实测梁高 H/L = 1/15.4 比经验上界 1/16 略高**。若按 `model_conformance` 严格评分,D2 梁高合理性会扣 0.5 分(得 0.5);工程上仍是合理设计,接受现状。

### 空心板截面 API

```python
sec = engine.section.create_hollowslab(
    no,                            # 截面编号(None 自动分配)
    name="标准截面",                # 截面名
    girder_pos="Middle",           # "Left" / "Middle" / "Right"
    h=0.75,                        # 梁高(m)
    bs=1.0,                        # 单片梁宽(m)
    # 其余参数用 api_read engine.section.create_hollowslab 查
    # 包含底板厚、腹板厚、空腔位置 / 尺寸等
)
```

**通用入口** `section.create(no, name, "HOLLOWSLAB", ...)` 也可用,多一个 `type` 路由参数,后续参数直接转 `create_hollowslab`。

**注意**:`SectionOffset` 仅边梁需要(向下偏置以让顶面对齐),中梁设 `0,Top`。

## 节点与单元 (→ prep/_5_node.py / _6_element.py, osis-module-node / osis-module-element)

### 节点分布(以 16m 实测为参考)

空心板跨内节点按**梁端加密 + 标准段均布**:

- **梁端段**:从 0.03m 起 0.46m、0.68m、1.68m、2.84m(锚固点周围加密)
- **跨中标准段**:约 2m 间距
- **次加密区**:13.16m、14.32m、15.32m、15.54m、15.97m(端横梁 / 支座附近;16m 实测)

### 改跨径时怎么改节点(近似命中必做)

不要整跨按「梁端 + 标准段」等比例重划——锚固点会错位,一端会挤出碎单元。与小箱梁同一方法:从已复制的 `_5` 认梁端加密簇(密间距),当刚体;`Δ` 只进跨中均布段。不要用固定米数切,不要改最右节点凑梁长。`L_new` 保留模板梁端边距。`_6` 截面号不动;`_2` 跨中直线段截 `Δ`。

写完自检:左右加密簇镜像、无过短碎单元、两端轮廓对称。

### 单元组(语义)

- `预制单元`:全跨所有 BEAM3D 单元
- `主梁单元`:同 `预制单元`(供 `_9_analysis` 车道引用)
- 简支变连续时:额外加 `现浇单元`(中墩顶湿接缝)
- `钢束投影组`:按 `钢束-{seq}-{tendon_name}线型单元` 命名

## 边界 (→ prep/_7_boundary.py, osis-module-boundary)

### 桥墩/桥台表达

- 桥台:锚固端,通过 boundary 表达,不显式建墩柱节点
- 中墩(简支变连续时):通过支座表达,体系转换时切换临时/永久支座

### 支座方案

| 部位 | 预制简支 | 先简支后连续 |
|---|---|---|
| 桥台 1(左) | 全约束(可释放 X) | 全约束(可释放 X) |
| 桥台 2(右) | 释放 X(滑动) | 释放 X(滑动) |
| 中墩(简支变连续) | 无 | 临时支座 → 体系转换 → 永久支座 |

空心板预制简支:仅 2 组永久支座;边界模板代码可直接用 `Boundary,1,GENERAL,,1,1,1,1,0,1,0` 和 `Boundary,2,GENERAL,,0,1,1,1,0,1,0`(7 个 bool=x,y,z,rx,ry,rz,rw,1=约束、0=释放;这里 ry=0 即释放绕 Y 的竖向弯曲转角,桥台 2 另放开 x 纵向滑动)。

## 荷载 (→ prep/_8_loadcase.py, osis-module-loadcase)

### 工况划分

模板 `_8` 实际工况名(预制简支,`_10` 按名引用,逐字一致):

| 类别 | 工况名 | 类型 |
|---|---|---|
| 主梁自重 | `主梁单元自重` | CS |
| 封端 | `封端混凝土工况` | CS |
| 二期 | `铺装工况` / `防撞护栏工况` | CS |
| 预应力 | `预应力` | CS |
| 温度 | `正温度梯度` / `负温度梯度` / `整体升温` / `整体降温` | CS |

活载不是工况,在 `_9` 里定义(`车道荷载包络`)。

### 温度

- 整体升温 +20℃、整体降温 -20℃(所有单元)
- 正温度梯度、负温度梯度(按规范 T 型混凝土空心板)

### 二期恒载

- 铺装 + 防撞护栏(线荷载值见项目画像或 `prep/_8_loadcase.py`)

## 钢束 (→ prep/_8_loadcase.py, osis-module-tendon)

### 分组

| 类别 | 含义 | 位置 | 是否必有 |
|---|---|---|---|
| 正弯矩束 | 跨内底板区域 | N1 / N2 共 2 束(实测样本) | 预制简支 + 变连续 |
| 负弯矩束 | 中墩顶翼缘 | T1 / T2 每中墩 2~4 束 | 仅变连续 |

实测 10/13/16m 用 **2 束**(N1 + N2),均在跨内底板区域。

### 张拉方案

- **两端张拉**(`tension_type="BOTH"`),`tension_force_type="ST"`(力控制)
- **张拉控制应力**:1.395e9 Pa(1395MPa,典型 0.75 × 1860MPa)
- **孔道参数**:μ=0.17, k=0.0015/m, 锚具变形 6mm/6mm, 松弛 0.3

### 预应力荷载工况

- `预应力`(CS1):全部正弯矩束,与主梁预制同期张拉;以所选模板 `_8` 为准

> 这个名字是 `_8` 的 `engine.load.create(<名>, "CS", ...)` 与 `_10` 的 `define_loadcase(..., <名>)` 之间的**契约名**,两处必须逐字一致,不得同义改写。钢束 shape 名只出现在 `_8` 的 `create("PST", ...)` 里,**不出现在 `_10`**。

### 钢束约束

- 钢束控制点 x 必须在 element_group(预制单元或现浇单元)覆盖范围内
- 钢束张拉阶段必须晚于对应构件激活阶段
- 负弯矩束只在墩顶湿接缝施工后(CS3)张拉

## 活载 (→ prep/_9_analysis.py, osis-module-analysis)

- **移动荷载标准**:`JTGD60_2015,HIGHWAY_I`
- **车道**:1 条(中线),车道长度取略小于跨径(避开锚固点)
- **横向折减系数**(固定):`[1.2, 1.0, 0.78, 0.67, 0.6, 0.55, 0.52, 0.5, 0.5, 0.5]`
- **冲击系数 μ**:跨径/梁型相关,数值看项目画像

## 施工阶段 (→ prep/_10_stage.py, osis-module-stage)

### 施工方法

预制厂预制主梁 → 张拉正弯矩束 → 存梁 → 架设到桥位(永久支座 / 临时支座)→ 浇筑墩顶湿接缝(变连续) → 张拉负弯矩束 → 体系转换 → 桥面铺装等二期恒载 → 长期徐变 → 运营。

### 阶段序列

**预制简支**:

```
CS1  主梁预制、张拉预应力(7d)
CS2  存梁(60d)
CS3  二期恒载(30d)
CS4  徐变十年(3650d)
CS5  运营阶段(0d)
```

**简支变连续(7 阶段,参考小箱梁/T 梁)**:

```
CS1  主梁预制、张拉正弯矩束(7d)
CS2  存梁(60d)
CS3  墩顶现浇段施工、张拉负弯矩束(7d)
CS4  体系转换(10d) ★ 关键
CS5  二期恒载(30d)
CS6  徐变十年(3650d)
CS7  运营阶段(0d)
```

## 模板与代码生成

### 模板位置与布局

目录树、builder 名、入口见总控 `osis-engine/references/template_layout.md`。本桥模板在 `references/templates/`(平铺)。

### 模板枚举(接到本桥型建桥任务第一件事)

1. `ls references/templates/`(平铺;本库目前只有预制简支 10/13/16m 中边梁)
2. **向用户显式报告** `共 N 个模板: [完整目录名, ...]`。名单像被截断 → 再 ls
3. **禁止**未列出全量就宣布「最近模板是 xxx」

### 匹配规则

按**体系 → 中/边梁 → 跨径**三级匹配;**仅当全量清单里没有同跨径+梁位时**才用最接近或最大跨径作 fallback。

### 模板 fallback 规则

跨径不匹配时,用跨径最接近的模板。截面几何保持原模板(梁高按分档表)。节点按 §节点与单元 改跨径时怎么改节点;钢束从跨中直线段截 `Δ`,梁端加密区跟节点走。

## 失败模式

- **右端碎单元 / 两端轮廓不对称** —— 整跨重划节点或改最右节点凑梁长。按 §节点与单元 改跨径时怎么改节点 重做
