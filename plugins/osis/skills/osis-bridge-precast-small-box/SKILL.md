# osis-bridge-precast-small-box

> 模板在 `references/templates/`,命中就复制(流程见 `osis-engine` §模板优先策略)。本文件写怎么选模板和改模板、本桥型的方案默认值和契约名。API 写法在各 `osis-module-*`。

## 必问参数

| 参数 | 选项(第一项为推荐) | 何时问 |
|---|---|---|
| 跨径(单跨) | 模板清单里的跨径,最接近用户需求的排第一 | 没提跨径 |
| 体系 | `先简支后连续`、`预制简支` | 用户想做连续时;没说"连续"默认预制简支 |
| 梁位 | `中梁`、`边梁` | 没提梁位(模板按梁位分) |

## 模板

模板清单现场列:`ls references/templates/`,目录名里写着体系、跨径、梁位。清单会更新,不要凭记忆报有哪些模板。

按**体系 → 梁位 → 跨径**匹配。没有同跨径的才用最接近的跨径,然后按下面的规程改。**不要等比例缩放截面和钢束**,截面保持模板原样。

### 改跨径时怎么改节点

只动**本跨跨中标准段**的 x。不要改最右节点去凑梁长,不要整桥 `x *= L_new/L_old`。

从复制来的 `_5` **认簇,不要用固定米数切**:间距密的是梁端锚固簇(简支变连续还有墩顶簇),约 1~2m 均布的是标准段。多跨时**逐跨**做。

记模板跨长 `L_old`(该跨最右节点 x − 最左节点 x)、目标跨长 `L_new`(保留模板的梁端边距,不要让最右节点等于用户口头说的跨径),`Δ = L_old − L_new`:

1. **左簇**:相对本跨左端的 x 不变。
2. **右簇**:相对本跨右端的偏移不变,随新梁端平移:`x' = 新右端 − (旧右端 − x)`。
3. **标准段**:把旧标准段区间仿射到新区间,或删掉/缩短其中的均布单元来吸收 `Δ`。节点号、单元连接、`_6` 的 `sec1/sec2` 不动。
4. **钢束**:`_2` 里跨中直线段截去 `Δ`;落在簇里的控制点跟节点走。改了 `_5` 没改 `_2`,钢束会停在旧坐标上,穿梁或出投影组。

自检:本跨左右加密簇关于跨中镜像;没有过短的碎单元;侧立面两端加厚段对称。一端挤出碎单元或两端不对称,说明是从梁端砍的,按 1~3 重做。

等跨的模型改跨径后,同一跨内截面分配保持纵向对称(左右过渡段、墩顶加厚段长度相等)。

## 方案默认值

以复制来的模板为准;从零写或用户没给时用下表。

| 跨径 | 梁高 | 标准段腹板厚 | 中墩顶腹板厚 |
|---|---|---|---|
| 20m | 1.2m | 0.16~0.18m | 0.25~0.30m |
| 25m | 1.4m | 0.18m | 0.30m |
| 30m | 1.6m | 0.20m | 0.30m |
| 35m | 1.8m | 0.20m | 0.30~0.32m |
| 40m | 2.0m | 0.18~0.20m | 0.32~0.36m |

| 项 | 默认 |
|---|---|
| 材料 | 主梁 C50;钢绞线 Strand1860 |
| 截面 | 标准截面 + 墩顶加厚截面 + 过渡段截面;中梁顶宽 2.4m,边梁 3.3m(含外侧翼缘) |
| 节点 | 每跨:梁端锚固簇(距梁端 0.08m、0.58m、0.88m)+ 标准段 1~2m 均布;简支变连续在墩顶湿接缝范围加密到 0.2~0.5m |
| 单元组 | `预制单元`、`现浇单元`(墩顶湿接缝,仅简支变连续)、`主梁单元`(车道参照) |
| 钢束投影组 | `钢束-{序号}-{钢束名}线型单元`,序号全桥连续编 |
| 墩台 | 不建墩柱,用支座表达 |
| 荷载 | 预制/现浇单元自重;二期 = 铺装 + 护栏;端横梁用节点集中力。数值看项目画像 |
| 活载 | 1 条车道,长度略小于跨径;**横向分布系数**填进活载子工况的 `scalar`,取模板或项目画像的值(没有时中梁 0.65、边梁 0.85),不要用 1.0;冲击系数用 `CUSTOM` + 基频 |
| 激活龄期 | 预制梁、现浇段激活时 `birth` 都是 7d |

## 钢束

| 类别 | 含义 | 预应力工况(契约名) | 张拉阶段 |
|---|---|---|---|
| 正弯矩束 `N1`、`N2`… | 跨内 | `预应力腹板束` | CS1 |
| 负弯矩束 `T1`、`T2` | 中墩顶(仅简支变连续) | `预应力顶板束` | CS3,墩顶现浇段激活的同一阶段 |

两个工况名在 `_8` 创建、`_10` 引用,逐字一致,不要换说法。束数和规格以模板为准。

## 施工阶段与体系转换

**预制简支**:

```
CS1  主梁预制、张拉正弯矩束(7d)
CS2  存梁(60d)
CS3  二期恒载(30d)
CS4  徐变十年(3650d)
CS5  运营阶段(0d)
```

支座:一端 x 向固定,另一端 x 向滑动,CS1 起激活。

**简支变连续**:

```
CS1  主梁预制、张拉正弯矩束(7d)        激活 临时支座-左 / 临时支座-右
CS2  存梁(60d)
CS3  墩顶现浇段施工、张拉负弯矩束(7d)   激活现浇单元,临时支座仍在
CS4  体系转换(10d)                     激活 4 组永久支座,钝化两组临时支座
CS5  二期恒载(30d)
CS6  徐变十年(3650d)
CS7  运营阶段(0d)
```

永久支座 4 组:一个中墩 x 向固定,其余中墩和两个桥台 x 向滑动。
