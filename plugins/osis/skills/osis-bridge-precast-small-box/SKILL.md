# osis-bridge-precast-small-box

> 章节顺序与 `_0`~`_10` 模块对齐,按"截面 → 节点 → 单元 → 边界 → 荷载 → 钢束 → 活载 → 阶段"顺序对应写 `prep/_N.py`。

## 必问参数 (question 工具)

用户提示缺这些参数时,打包成一个 question 调用一次问完。options 用本 SKILL 表格里的标准值,第一项为推荐默认。

| 参数 | 选项(第一项为推荐) | 何时可省 |
|---|---|---|
| 跨径(单跨 L) | `20m`、`25m`、`30m`、`35m`、`40m` | 用户没提跨径时必问 |
| 桥宽 | `16.75m`、`12.75m`、`其他` | 模板里没有等宽时必问 |
| 体系 | `先简支后连续`、`预制简支` | 没说"连续"时默认预制简支;想做连续必问 |
| 梁位 | `中梁`、`边梁` | 模板按梁位区分,必问 |

## 截面 (→ prep/_4_section.py, osis-module-section)

### 截面方案

- 小箱梁:**标准截面 + 墩顶加厚截面 + 过渡段截面**

- 截面数量:每跨约 2~5 个

| 跨径 | 典型梁高 | 标准段腹板厚 | 中墩顶腹板厚 | 钢束数(正弯矩/跨) |
|---|---|---|---|---|
| 20m | 1.2m | 0.16~0.18m | 0.25~0.30m | 3~4 束 |
| 25m | 1.4m | 0.18m | 0.30m | 4 束 |
| 30m | 1.6m | 0.20m | 0.30m | 4 束 |
| 35m | 1.8m | 0.20m | 0.30~0.32m | 4~5 束 |
| 40m | 2.0m | 0.18~0.20m | 0.32~0.36m | 4~5 束 |

### 体系差异

| 维度 | 预制简支 | 简支变连续(先简支后连续) |
|---|---|---|
| 中墩顶构件 | 无 | 现浇段(湿接缝) |
| 钢束分组 | 仅正弯矩束 | 正弯矩束 + 负弯矩束 |

## 节点 (→ prep/_5_node.py, osis-module-node)

每跨内节点按**锚固段加密 + 标准段均布 + 墩顶加密**三段:

- **锚固段**:从梁端 0.08m 起,经 0.58m、0.88m 三点加密(锚固点 ~0.08m,渐疏到 0.88m)
- **跨中标准段**:1~2m 间距
- **墩顶加密**(简支变连续时):0.2~0.5m 间距,覆盖湿接缝范围

多跨时按"上一跨终点 + 本跨偏移"累加。跨数:1 跨(纯简支)、2~5 跨(简支变连续)。


### 改跨径时怎么改节点(近似命中必做)

库档是 20/25/30/35/40m。用户跨径落在档间时,按总控复制最近档,然后只动**本跨跨中标准段**的 x。不要改最右节点凑梁长,不要整桥 `x *= L_new/L_old`。

从已复制的 `_5` **认簇,不要用固定米数切**:间距密的是梁端锚固簇(简支变连续还有墩顶簇),约 1~2m 均布的是标准段。多跨时**逐跨**做,墩顶簇和梁端簇一样冻。

对本跨:记模板跨长 `L_old`(该跨最右节点 x − 最左节点 x),目标跨长 `L_new`(保留模板的梁端边距,不要强行让最右节点等于用户口头跨径)。`Δ = L_old - L_new`。

1. **左簇**:相对本跨左端的 x 原样。
2. **右簇**:相对本跨右端的偏移不变,随新梁端平移:`x' = 新右端 - (旧右端 - x)`。
3. **标准段**:把旧标准段区间仿射到新区间,或删掉/缩短其中的均布单元吸收 `Δ`。节点号、单元连接、`_6` 的 `nSec1/nSec2` 不动。
4. **钢束**:`_2` 跨中直线段截去 `Δ`;落在冻结簇里的控制点跟节点走。

演示(仅此一例,勿把坐标抄到别的跨径/梁位):30m 中梁模板 `L_old=29.96`,用户要 28m → `L_new=27.96`。左簇 `0.04/0.58/0.84/2.84` 不动;右簇按距梁端偏移搬到新右端;只压缩中间均布段。

写完自检:本跨左右加密簇关于跨中镜像;无过短碎单元;侧立面两端加腋/加厚对称。不对称或一端挤单元 = 从梁端砍了,按 1~3 重做。


## 单元 (→ prep/_6_element.py, osis-module-element)

### 构件组(语义)

| 体系 | 需要的构件组 |
|---|---|
| 预制简支 | `预制单元`(每跨 1 个) + `主梁单元`(车道引用) |
| 简支变连续 | `预制单元`(每跨 1 个) + `现浇单元`(中墩顶湿接缝) + `主梁单元`(车道引用) |

### 钢束投影组

按 `钢束-{seq}-{tendon_name}线型单元` 命名,`seq` 是 1~N 全局序号,`tendon_name` 由钢束名决定。

### 车道引用组

`主梁单元`:包含全部主梁单元,供 `_9_analysis` 引用车道。

## 边界 (→ prep/_7_boundary.py, osis-module-boundary)

### 桥墩/桥台表达

- 桥台:锚固端,通过 boundary 表达,不显式建墩柱节点
- 中墩(简支变连续时):通过支座表达,体系转换时切换临时/永久支座

### 中梁/边梁节点偏置差异

| 维度 | 中梁 | 边梁 |
|---|---|---|
| 单片梁宽 | 2.4m | 3.3m(含外侧翼缘) |
| 顶板宽 | 1.65m | 2.55m |
| 翼缘长度 | 0.75m(两侧) | 0.75m |
| 护栏 | 不含 | 含(边梁额外荷载) |

### 支座方案

| 部位 | 永久支座 | 临时约束 |
|---|---|---|
| 桥台 1(左) | 全约束(可释放 X) | — |
| 桥台 2(右) | 释放 X(滑动) | — |
| 中墩(简支变连续) | 简支阶段:临时支座;体系转换后:永久支座 | 简支阶段激活 |

简支阶段激活 2 组临时支座(临时支座-左、临时支座-右,跨内两支座共用);体系转换时激活 4 组永久支座(桥墩1 固定、桥墩2 滑动、桥台1 滑动、桥台2 滑动),钝化临时支座。

### 体系转换时序(仅简支变连续)

- **CS3 墩顶现浇段施工**:激活现浇单元 + 钝化临时支座 + 激活负弯矩束
- **CS4 体系转换**(关键节点):激活中墩永久支座

## 荷载 (→ prep/_8_loadcase.py, osis-module-loadcase)

### 自重与二期

- **自重**:主梁/预制/现浇 自重工况, g = -1.040 m/s²(考虑钢筋系数)
- **二期恒载**:铺装工况 + 防撞护栏工况(线荷载值看项目画像)
- **端横梁**:节点集中力(数值和节点号看项目画像)

### 温度

- 整体升温 +20℃、整体降温 -20℃(所有单元)
- 正温度梯度、负温度梯度(按规范 T 型)

## 钢束 (→ prep/_8_loadcase.py, osis-module-tendon)

### 分组(2 类)

| 类别 | 含义 | 数量 |
|---|---|---|
| 正弯矩束 | 跨内(每跨 4~5 束) | 5 束/跨 × 跨数 |
| 负弯矩束 | 中墩顶(每中墩 T1+T2 两束) | 2 束/中墩 × 中墩数(仅简支变连续) |

具体命名(`N1`/`N2`/.../`T1`/`T2`/`N1-1` 等)由本项目决定。规格从 `15-3` / `15-4` / `15-5` / `15-6` / `15-7` / `15-8` / `15-9` / `15-10` 中按束力选。

### 张拉方案

- **两端张拉**(`tension_type="BOTH"`),`tension_force_type="ST"`(力控制)
- **张拉控制应力**:1.395e9 Pa(1395MPa,典型 0.75 × 1860MPa)
- **孔道参数**:μ=0.17, k=0.0015/m, 锚具变形 6mm/6mm, 松弛 0.3

### 预应力荷载工况

- `预应力腹板束`(CS1):正弯矩束
- `预应力顶板束`(CS3):负弯矩束(简支变连续才有)

> 这两个名字是 `_8` 的 `engine.load.create(<名>, "CS", ...)` 与 `_10` 的 `define_loadcase(..., <名>)` 之间的**契约名**,两处必须逐字一致,不得同义改写。钢束 shape 名(`N1-1`/`T2-1` 等)只出现在 `_8` 的 `create("PST", ...)` 里,**不出现在 `_10`**。

### 钢束约束

- 钢束控制点 x 必须在 element_group(预制单元或现浇单元)覆盖范围内
- 钢束张拉阶段必须晚于对应构件激活阶段
- 负弯矩束只在墩顶湿接缝施工后(CS3)张拉

## 活载 (→ prep/_9_analysis.py, osis-module-analysis)

- **移动荷载标准**:`JTGD60_2015,HIGHWAY_I`
- **车道**:1 条(中线),车道长度取略小于跨径(单跨加载,避开锚固点)
- **横向折减系数**(固定):`[1.2, 1.0, 0.78, 0.67, 0.6, 0.55, 0.52, 0.5, 0.5, 0.5]`
- **冲击系数 μ**:跨径/梁型相关,数值看项目画像
- **横向分布系数**:写入 `live.case.include(..., scalar, …)` / `create_sub(scalar=…)`(命令流 `LiveAnalInc` 的 scalar)。典型:中梁 `0.65`、边梁 `0.85`;禁止默认 `1.0`

## 施工阶段 (→ prep/_10_stage.py, osis-module-stage)

### 施工方法

预制厂预制主梁 → 存梁 → 架设到桥位(临时支座) → 浇筑墩顶湿接缝(简支变连续) → 张拉负弯矩束 → 体系转换 → 桥面铺装等二期恒载 → 长期徐变 → 运营

### 阶段序列轮廓

**预制简支(5 阶段)**:

```
CS1  主梁预制、张拉正弯矩束(7d)
CS2  存梁(60d)
CS3  二期恒载(30d)
CS4  徐变十年(3650d)
CS5  运营阶段(0d)
```

**简支变连续(7 阶段)**:

```
CS1  主梁预制、张拉正弯矩束(7d)
CS2  存梁(60d)
CS3  墩顶现浇段施工、张拉负弯矩束(7d)
CS4  体系转换(10d) ★ 关键
CS5  二期恒载(30d)
CS6  徐变十年(3650d)
CS7  运营阶段(0d)
```

## 模板与代码生成

### 模板位置与布局

目录树、builder 名、入口见总控 `osis-engine/references/template_layout.md`。本桥模板在 `references/templates/`(平铺)。

### 模板枚举(接到本桥型建桥任务第一件事)

1. `ls references/templates/`(平铺;`简支变连续-*` 与 `预制简支-*` 都在这一层)
2. **向用户显式报告** `共 N 个模板: [完整目录名, ...]`。名单像被截断 → 再 ls
3. **禁止**未列出全量就宣布「最近模板是 xxx」

### 匹配规则

在报出全量之后,按**体系(简支/简支变连续) → 中/边梁 → 跨径**三级匹配。**仅当全量清单里没有同跨径+梁位时**才用最接近跨径。

### 模板 fallback 规则

跨径不匹配时(**须已 ls 报全量且清单无同跨径+梁位**),用跨径最接近的模板。截面几何保持原模板,**不要**等比例缩放截面或钢束。节点按 §节点 改跨径时怎么改节点;钢束从跨中直线段截去 `Δ`,冻结簇内布置跟节点走。

### 简支 / 等跨连续的纵向对称

**单跨简支**与**等跨径连续**(含等跨简支变连续)改跨时,同跨内须沿纵向对称:

- 左右过渡段(加厚截面 ↔ 标准截面)长度相等
- 左右墩顶截面段长度相等
- 节点坐标可不绝对对称,但截面分配必须对称

**不等跨连续**不要求同跨内对称。

## 失败模式

- **右端碎单元 / 两端加腋不对称** —— 近似命中后把最右节点改成目标梁长,或整桥缩放。按 §节点 改跨径时怎么改节点 重做;`_6` 截面号不要重排
- **改了 `_5` 没改 `_2`** —— 钢束控制点仍停在旧绝对 x,穿梁或出组。跨中直线段截 `Δ`,冻结簇内跟节点走
