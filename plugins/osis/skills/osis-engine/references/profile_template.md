# 项目画像模板

> 本文件由 AI 维护,记录本项目特定参数。通用建模规则按对应桥型 SKILL 执行。

## 章节结构(9 节,按 prep/_N.py 模块对齐)

项目画像按以下 9 章节写,结构与 `_3_material` 到 `_10_stage` 的 `prep/` 模块一一对应,方便 OSIS-AI 写代码时按章节对照 SKILL。

| 章节 | 对应模块 | 必含字段 |
|---|---|---|
| 1. 项目定位 | — | 桥型、体系、跨径、总长、梁位、桥宽、单片梁宽、梁高、湿接缝/合龙段 |
| 2. 材料 | `_3_material` | 主梁/桥墩混凝土、钢筋、钢绞线、收缩徐变 |
| 3. 截面 | `_4_section` | 类型、截面数量、顶/底/腹板厚、箍筋 |
| 4. 节点与单元 | `_5_node` + `_6_element` | 节点范围、单元组清单 |
| 5. 边界体系 | `_7_boundary` | 施工阶段、体系转换阶段的支座激活/钝化 |
| 6. 钢束 | `_8_loadcase` | 正/负弯矩束数量与规格、其他束类 |
| 7. 荷载 | `_8_loadcase` | 端横梁、二期恒载 |
| 8. 活载分析 | `_9_analysis` | 车道数、长度、冲击系数 |
| 9. 施工阶段 | `_10_stage` | CS1~CSn 名称、时长、主要动作(用表格) |

**不要在画像里写 SKILL 默认值**:跨径分档、横向折减系数、张拉控制应力(1395MPa)、温度 ±20℃ 等模式内容都不进画像,那些在对应桥型 SKILL 里。

**§4 是占位**:首次跑通 `prep/_5_node.py` + `_6_element.py` 后回填节点数/单元数/锚固点位置,实现模板→项目的快速复刻。字段缺失留 `<!-- TODO -->`。
