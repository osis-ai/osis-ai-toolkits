# 连续刚构变截面梁高推算

公式、坐标与悬浇连续梁相同,见 `osis-bridge-cantilever-box/references/section_parabola.md`。本页只补刚构的 **n 分档** 和 200m 模板算例。

```
h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n
```

- `x`:距 **0 号块外缘**(变化段起点)。0 号块内 `h = h_root`;合龙/跨中平台 `h = h_mid`
- `L`:变化段长度 = 半主跨 − 合龙段半长 − 0 号块半宽
- **不要默认 n=2**;改 n 按桩号重算 h,禁止从旧高度开方反推指数

## n 怎么取(连续刚构)

| 主跨 | 取 n | 模板 |
|---|---|---|
| [70, 120) m | 1.8 或 2.0 | 95+95 单肢现浇高度拟合约 1.4,新建不要照抄 |
| [120, 150] m | **1.8** | — |
| (150, 200] m | **1.5** | 160/170/180/190/200m 双肢模板均为 1.5 |
| (200, 250] m | **1.5** | — |

刚构 0 号块更长(墩中心两侧常见 5~8m),更不能把 x 从墩中心起算。

## 算例:108+200+108 双肢(与模板一致)

- 半主跨 100m,0 号块半宽 7m,合龙段半长 1m
- **L = 100 − 1 − 7 = 92m**
- h_root = 11.5m,h_mid = 4.8m,**n = 1.5**(画像若写 n=2 是错的)

`x` 从 0 号块外缘起;距墩中心 `s = x + 7`。

| 位置 | s 距墩中心 (m) | x (m) | h (m) |
|---|---:|---:|---:|
| 0 号块平台 | 0~7 | (平台) | 11.500 |
| 变化段起点 | 7.5 | 0.5 | 11.445 |
| 近跨中 | 94.5 | 87.5 | 4.872 |
| 跨中平台 | ≥99 | ≥92 | 4.800 |

验算(x=0.5):`h = 4.8 + 6.7 * (1 - 0.5/92)^1.5 = 11.445`。
