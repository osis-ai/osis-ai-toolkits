# 变截面连续刚构-90+170+90-双肢

> 本文件由AI维护,记录本桥项目特定参数。通用建模规则按 `osis-bridge-rigid-frame-box` 执行。

---

## 1. 项目定位

- 桥型:变截面连续刚构
- 体系:三跨连续刚构(墩梁固结)
- 跨径:90 + 170 + 90m,总长 350m
- 桥宽:12.75m
- 单片梁宽:6.375m(单箱单室,顶宽)
- 主梁材料:C60
- 桥墩材料:C45(双肢薄壁墩)
- 桥墩形式:双肢薄壁墩
- 截面形式:单箱单室
- 节段对数:每 T 构 20 对节段 + 3 个 0 号截面
- 合龙段:边跨 + 中跨 1 个

## 2. 材料

- 主梁混凝土:C60
- 桥墩混凝土:C45
- 普通钢筋:HRB400
- 钢绞线:Strand1860
- 精轧螺纹钢(临时束):Rebar785
- 收缩徐变:avg_humidity=75%, birth_time=7d, type_coeff=5.0, shrink_birth=3

## 3. 截面

- 类型:单箱单室变截面(主梁) + 矩形桥墩
- 截面数量:26 个(跨中 1 + 边跨现浇 1 + 悬浇渐变 20 + 0 号段 3 + 桥墩 RECT 1)
- 梁高:
  - 跨中 h_mid:3.8m
  - 桥墩 h_root:10.0m
  - 公式:`h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n`,n=1.5
  - x:距 0 号块外缘(变化段起点);0 号块内 h=h_root;合龙/跨中平台 h=h_mid
  - L:变化段长度 = 半主跨 − 合龙段半长 − 0 号块半宽
- 桥墩矩形:2.5m × 7m(单肢,prep RECT)
- 顶板宽:6.375m,底板宽:3.5m
- 腹板厚:
  - 跨中标准段:0.50m
  - 悬浇渐变段:0.5~0.75m
  - 桥墩附近(0 号段):0.75~1m
  - 边跨现浇段:0.75m
- 顶板厚:跨中 0.28m,根部 0.28m
- 底板厚:跨中 0.32m,根部 1.0m
- 悬臂长度:2.875m(顶宽-底宽,两侧)
- 网格尺寸:0.1m

## 4. 节点与单元

- 总节点数:227
- 总单元数:222
- 单元组:
  - 0 号块单元
  - 1~20 号块单元(每 T 构 20 对)
  - 边跨现浇段
  - 左边跨合龙段 / 右边跨合龙段
  - 中跨 1 合龙段 / 中跨合龙段
  - 桥墩单元组(双肢)
  - 弹簧单元_桥台 1_顶底 / 弹簧单元_桥台 2_顶底
  - 主梁单元

## 5. 边界体系

- 墩梁固结:双肢桥墩顶各 1 处,共 4 处(2 桥墩 × 2 肢)
- 墩底固定:双肢桥墩底共 4 处
- 边跨临时支架:左、右边跨施工时激活,边跨合龙时钝化
- 桥台支座(CS63 激活):
  - 桥台 1_横向固定_纵向释放
  - 桥台 1_横向释放_纵向释放
  - 桥台 2_横向固定_纵向释放
  - 桥台 2_横向释放_纵向释放
- 桥台沉降组:桥台 1、桥台 2 各 10mm;桥墩 1、桥墩 2 各 15mm

## 6. 钢束

- 张拉控制应力:1.395e9 Pa(两端张拉)
- 规格:15-17 / 15-18 / 15-19 / 15-21 / 15-23
- 共 167 束(命名去重),分 6 类:
  - BB(边跨底板):28 束,BB10-y ~ BB9-z
  - BT(边跨顶板):26 束,BT10-y ~ BT9-z
  - F(跨中腹板):42 束,F0-1 ~ F9-2
  - T(跨中顶板):42 束,T0-1 ~ T9-2
  - ZB(中跨底板):15 束,ZB10-1 ~ ZB9-1
  - ZT(中跨顶板):14 束,ZT10-1 ~ ZT9-1
- 边跨底板束端部定位:距梁端 0.2m

## 7. 荷载

- 自重:各节段、桥墩、合龙段 单独自重工况
- 二期恒载:铺装(左右半幅) + 防撞护栏(左右)
- 沉降:桥墩 1、桥墩 2 各 15mm;桥台 1、桥台 2 各 10mm
- 温度:整体升降温 + 正负温度梯度

## 8. 活载分析

- 车道数:左偏 2 车道 + 中载 2 车道 + 右偏 2 车道(共 3 个工况)
- 车道长度:170m(中跨满跨加载)
- 冲击系数:μ=1.35(CUSTOM)

| 阶段 | 名称 | 时长 | 主要动作 |
|---|---|---:|---|
| CS1 | 下部及 0 号段施工 | 28d | 激活 0 号块、桥墩、墩底固定点、墩梁固结、自重、预应力 |
| CS2~CS61 | 1~20 号段 × (挂 1d + 浇 8d + 张 1d) | 各 10d | 挂篮激活/钝化、湿重激活/钝化、节段激活、张拉预应力 |
| CS62 | 边跨支架现浇 | 12d | 激活边跨现浇段、左/右边跨临时支架、边跨合龙湿重、吊架荷载 |
| CS63 | 边跨合龙 | 12d | 激活桥台永久支座、弹簧单元、左/右合龙段、预应力;钝化临时支架 |
| CS64 | 中跨 1 合龙 | 12d | 激活中跨合龙段、张拉中跨预应力 |
| CS65 | 二期恒载 | 60d | 激活铺装、防撞护栏 |
| CS66 | 徐变十年 | 3650d | 长期效应 |
