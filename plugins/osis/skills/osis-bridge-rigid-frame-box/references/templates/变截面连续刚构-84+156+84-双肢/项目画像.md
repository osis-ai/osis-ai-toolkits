# 变截面连续刚构-84+156+84-双肢

> 本文件由AI维护,记录本桥项目特定参数。通用建模规则按 `osis-bridge-rigid-frame-box` 执行。
> 来源:`84+156+84m刚构梁宽10.75m-修改部分错误.out`(CUSTOM 点截面已转 CONVENTIONALBOX)。

---

## 1. 项目定位

- 桥型:变截面连续刚构
- 体系:三跨连续刚构(墩梁固结)
- 跨径:84 + 156 + 84m,总长 324m(节点 x=0~324)
- 桥宽:主梁多数 **10.75m**(顶板半宽 5.375m);19~27 号块及部分截面顶半宽 6.35m(全宽 12.7m,原模型如此,入库未改)
- 单片梁宽:5.375m(单箱单室,顶宽,标准段)
- 主梁材料:C55
- 桥墩材料:C40
- 桥墩形式:双肢薄壁墩,RECT 6.0m × 2.5m(实心)
- 截面形式:单箱单室
- 节段:块 0 + 块 1~26;0 号后悬浇至 18 号等高段,对侧 19~27
- 合龙:边跨合拢 + 中跨合拢(先边后中,中跨前有合拢顶推)

## 2. 材料

- 主梁混凝土:C55(JTGD62_2004)
- 桥墩混凝土:C40(JTGD62_2004)
- 钢绞线:Strand1860
- 收缩徐变:C55 / C40 各一条,avg_humidity=70%, birth_time=28d, type_coeff=5.0, shrink_birth=3

## 3. 截面

- 类型:单箱单室变截面(CONVENTIONALBOX) + 矩形桥墩
- 截面数量:137 个(含单元端插值);命名截面含 0~18 号、19~27 号块、桥墩
- 梁高:
  - 跨中等高段 h_mid:3.6m(18 号截面)
  - 根部 / 0 号 h_root:10.0m
- 桥墩矩形:6.0m × 2.5m
- 标准段顶板半宽 5.375m、底板半宽 3.0m、悬臂长 2.375m
- 腹板厚:跨中约 0.55m,根部约 0.90m
- 顶板厚:约 0.30m;底板厚跨中约 0.32m,根部约 1.30m
- 网格尺寸:0.1m
- 主梁偏移:Middle / Top

## 4. 节点与单元

- 总节点数:181
- 总单元数:172
- 单元组:127 个(块 0~26、边跨现浇段、桥墩、钢束组等)

## 5. 边界体系

- 下部结构与 0 号块阶段激活墩底 / 墩梁固结
- 边跨合拢:激活桥台永久支座(主梁节点 1、2 与 177、178;横固+竖向),同时钝化边跨现浇段临时支架
- 合拢顶推后中跨合拢,再拆除吊架
- 桥台支座打在主梁节点上,不用偏置虚节点 181–184 做 RIGID 从节点(与 GENERAL 叠 Fz 会导致 Solve 失败)

## 6. 钢束

- 钢束形状:94 条
- 规格(体内):15-15.2、17-15.2、21-15.2(边底/边顶/顶板/腹板/中底/中顶等)
