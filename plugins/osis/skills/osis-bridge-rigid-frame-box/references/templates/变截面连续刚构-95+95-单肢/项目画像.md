# 变截面连续刚构-95+95-单肢

> 本文件由AI维护,记录本桥项目特定参数。通用建模规则按 `osis-bridge-rigid-frame-box` 执行。

---

## 1. 项目定位

- 桥型:变截面连续刚构(双跨,T 形)
- 体系:**墩梁固结无永久支座**;主梁与单肢桥墩刚结
- 跨径:95 + 95m,总长 190m(97m 为桥台节点,含边跨锚固)
- 桥宽:12.75m
- 单片梁宽:6.375m(单箱单室,顶宽)
- 主梁材料:C55
- 桥墩材料:C45(单肢矩形墩,2m × 7m)
- 截面形式:单箱单室
- 节段对数:每 T 构 17 对节段 + 1 个 0 号段(主跨 95m,刚构节段对数偏多)
- 合龙段:边跨合龙 + 中跨合龙,中跨不另体系转换(刚构连续)

## 2. 材料

- 主梁混凝土:C55
- 桥墩混凝土:C45
- 普通钢筋:HRB400
- 钢绞线:Strand1860
- 收缩徐变:avg_humidity=75%, birth_time=7d, type_coeff=5.0, shrink_birth=3

## 3. 截面

- 类型:单箱单室变截面(主梁) + 矩形桥墩
- 截面数量:20 个(跨中 1 + 桥墩 1 + 边跨现浇 1 + 悬浇渐变 16 + 0 号段 1)
- 梁高:
  - 跨中 h_mid:4.5m(L/21)
  - 桥墩 h_root:9.0m(L/10.6,刚构主墩无永久支座,受力大,h_root 较悬浇梁加深)
  - 公式:`h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n`,n=1.4
  - x:距 0 号块外缘(变化段起点);0 号块内 h=h_root;合龙/跨中平台 h=h_mid
  - L:变化段长度 = 半主跨 − 合龙段半长 − 0 号块半宽
- 桥墩矩形:2.0m × 7m(单肢)
- 顶板宽:6.375m,底板宽:6.375m
- 腹板厚:跨中标准段 0.50m,桥墩 0.30m

## 4. 节点与单元

- 节点:77 个,x 终点 97.0m;节点 77 z=-29m(墩底)
- 单元:74 个 beam3d
- 单元组:`0号块单元`、`1~17号块单元`、`合龙段单元`(边跨 + 中跨)、`边跨现浇段单元`、`桥墩单元`、`主梁单元`、钢束投影组

## 5. 边界体系

**刚构无永久支座**,主梁与桥墩固结:

- 桥墩:**墩梁固结**(主从约束,节点 1/3)+ **墩底固定点**(节点 2/4)
- 桥台 1/2:横固纵释 + 横释纵释 两组(锚固端,无桥墩)
- 桥台 1:横固纵释 + 横释纵释(节点 9/10)
- 桥台 2:横固纵释 + 横释纵释(节点 11/12)

## 6. 钢束

- 张拉控制应力:1.395e9 Pa(两端张拉,ST)
- 规格:15-7 / 15-9 等
- 68 束,6 类(每束配 z 镜像 + 复制):
  - BB(边跨底板束):BB5~BB14 × 2 = 20 束
  - BT(边跨顶板束):BT12~BT17 × 2 = 12 束
  - F(跨中腹板束):F0~F17 × 2 = 36 束
  - T(跨中顶板束):T0~T17 × 2 = 36 束
  - ZB/ZT:中跨束(数量较少)
- 孔道参数:μ=0.17, k=0.0015/m, 锚具变形 6mm/6mm, 松弛 0.3
- 边跨底板束(BB)起/终点距梁端 0.2m

## 7. 荷载

- 自重:0号块~17号块 各自重工况, g = -9.8066 m/s²
- 端横梁:节点集中力(数值和节点号看项目画像)
- 二期恒载:铺装 + 防撞护栏(左右半幅)
- 温度:整体升降温 ±20℃;正负温度梯度

## 8. 活载分析

- 移动荷载标准:`JTGD60_2015,HIGHWAY_I`
- 车道:3 个工况(左偏 / 中载 / 右偏),车道长度取中跨满跨
- 横向折减系数(固定):`[1.2, 1.0, 0.78, 0.67, 0.6, 0.55, 0.52, 0.5, 0.5, 0.5]`
- 冲击系数 μ:跨径/梁型相关,数值看项目画像
- 沉降:桥墩 10~15mm,桥台 10mm

## 9. 施工阶段

阶段数 57(17 节段对 + 收尾)。轮廓:

```
CS1       下部及 0 号段(28d)
CS2~CS52  1~17 号段 × (挂篮 1d + 浇筑 8d + 张拉 1d)
CS53      边跨支架现浇(12d)
CS54      边跨合龙(12d) ★
CS55      二期恒载(60d)
CS56      徐变十年(3650d)
CS57      运营阶段(0d)
```

阶段时长模板:
- 0 号段:28d
- 每个悬浇节段:挂 1d + 浇 8d + 张 1d = 10d
- 边跨合龙:12d
- 二期:60d
- 徐变:3650d
- 运营:0d

**刚构无独立"中跨合龙"和"体系转换"阶段**:主梁与桥墩本就是刚结,合龙后无需体系转换(CS54 边跨合龙后直接进二期)。
