# 变截面连续刚构-65+120+65-双肢

> 本文件由AI维护,记录本桥项目特定参数。通用建模规则按 `osis-bridge-rigid-frame-box` 执行。
> 来源:`G346（65+120+65）m刚构V2定稿.out`(CUSTOM 点截面已转 CONVENTIONALBOX)。

---

## 1. 项目定位

- 桥型:变截面连续刚构
- 体系:三跨连续刚构(墩梁固结)
- 跨径:65 + 120 + 65m,总长 250m(节点 x=0~250)
- 桥宽:**9.5m**(顶板半宽 4.75m);模型里另有旧 12.5m 截面(13号块_旧_、16/17号等高段等),单元未引用,入库未删
- 单片梁宽:4.75m(单箱单室,顶宽,标准段)
- 主梁材料:C55
- 桥墩材料:C40
- 桥墩形式:双肢薄壁墩,RECT 5.5m × 2.0m(实心);肢距 6m(x=62/68 与 x=182/188)
- 截面形式:单箱单室
- 节段:块 0 + 块 1~14 + 边跨现浇段
- 合龙:边跨合拢 + 中跨合拢(先边后中,中跨前有合拢顶推)

## 2. 材料

- 主梁混凝土:C55(JTG3362_2018)
- 桥墩混凝土:C40(JTG3362_2018)
- 钢绞线:Strand1860
- 收缩徐变:C55 / C40 各一条,avg_humidity=70%, birth_time=28d, type_coeff=5.0, shrink_birth=3

## 3. 截面

- 类型:单箱单室变截面(CONVENTIONALBOX) + 矩形桥墩
- 截面数量:209 个(208 箱梁含单元端插值 + 1 桥墩 RECT)
- 梁高:
  - 边跨现浇 / 跨中附近 h_mid:2.8m(15号_边跨现浇段)
  - 根部 / 0 号 h_root:7.5m
- 桥墩矩形:5.5m × 2.0m;1#墩底 z=-31.5m,2#墩底 z=-21.5m
- 标准段顶板半宽 4.75m、底板半宽 2.75m、悬臂长 2.0m
- 腹板厚:跨中约 0.50m,根部约 0.90m
- 顶板厚:标准段 0.30m,0 号约 0.50m
- 底板厚:跨中 0.32m,根部 1.20m
- 网格尺寸:0.1m
- 主梁偏移:Middle / Top
- 梁高抛物线:主跨 120m,n=1.8(见 skill 表 [120,150])

## 4. 节点与单元

- 总节点数:117
- 总单元数:108
- 单元组:202 个(块 0~14、边跨现浇段、边跨/中跨合拢段、桥墩、钢束组、车道线)
- 主梁节点顶缘 z=0,y=0

## 5. 边界体系

- 下部结构激活墩底固结;0 号块阶段墩梁固结
- 边跨现浇段临时支架(主梁节点 1/3/5 与 113/115/117)
- 边跨合拢:激活桥台永久支座(主梁 1、3 与 115、117;横固+竖向),同时钝化临时支架
- 合拢顶推后中跨合拢,再拆除吊架
- 桥台支座打在主梁节点上,不用偏置虚节点 2/4/114/116 做 RIGID 从节点(与 GENERAL 叠 Fz 会导致 Solve 失败)

## 6. 钢束

- 钢束形状:80 条
- 规格(体内):19-15.2(边跨底板/边跨顶板/顶板束/腹板束/中跨底板)
