# osis-bridge-rigid-frame-box

> 模板在 `references/templates/`,命中就复制(流程见 `osis-engine` §模板优先策略)。上部结构的做法与悬浇连续梁相同,本文件只写刚构的模板、方案默认值和与悬浇梁不同的地方;钢束分类和钢束优化读 `osis-bridge-cantilever-box` §钢束。API 写法在各 `osis-module-*`。

## 必问参数

| 参数 | 选项(第一项为推荐) | 何时问 |
|---|---|---|
| 跨径组合 | 模板清单里的跨径,最接近用户需求的排第一 | 没提跨径 |
| 桥墩形式 | `双肢薄壁墩`、`单肢实心墩` | 没提桥墩 |
| 桥宽 | 所选模板的桥宽(看它的项目画像)、其他 | 模板里没有同宽 |
| 主梁材料 | `C60`、`C55`、`C50` | 主跨 < 80m;≥ 80m 默认 C60 |
| 截面形式 | `单箱单室`、`单箱双室` | 主跨 > 120m;≤ 80m 默认单箱单室 |
| 节段对数(每 T 构) | 模板默认 | 没提节段方案 |

## 模板

模板清单现场列:`ls references/templates/`,目录名里写着跨径组合和单肢/双肢。清单会更新,不要凭记忆报有哪些模板。

按**桥墩形式(单肢/双肢)→ 跨径**匹配。

- 跨径、桥墩形式、桥宽、截面形式都对上的模板就是命中。只有 n、材料或节段数与用户要求不同时,复制它再改差异(n 不同按 `references/section_parabola.md` 重算变化段各截面 h),**不要换成另一个跨径的模板**。
- 没有同跨径的模板时才用跨径最接近的。**不要等比例缩放截面和钢束**:截面保持模板原样,只挪节点;钢束只在跨中直线段增减长度,曲线段不变。
- 只改跨中梁高走 `osis-edit-hmid`。
- `osis-bridge-cantilever-box` 的 `spanremap` 脚本只适用于它自己的三跨模板,不要拿来改刚构。

## 截面方案

变截面:跨中恒高段 + 边跨现浇段 + 悬浇渐变段 + 0 号块。梁高只在**变化段**用抛物线,与构造评分 D3 同一套坐标(详见 `references/section_parabola.md`):

`h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n`

- `x`:距 **0 号块外缘**的距离。0 号块内 `h = h_root`;合龙段和跨中平台 `h = h_mid`。
- `L`:变化段长度 = 半主跨 − 合龙段半长 − 0 号块半宽。刚构 0 号块长,不能从墩中心起算。
- `n`:按主跨取,**不要默认 2**。改 n 要按桩号重算各截面 h,不要从旧高度开方反推。

| 主跨 | n |
|---|---|
| [70, 120) m | 1.8 或 2.0 |
| [120, 150] m | 1.8 |
| (150, 250] m | 1.5 |

梁高经验值(根部比同跨径悬浇梁深 5~10%):

| 主跨 L | 根部 h_root | 跨中 h_mid |
|---|---|---|
| 60~80m | L/15 ~ L/17 | L/30 ~ L/38 |
| 80~120m | L/16 ~ L/19 | L/35 ~ L/45 |
| 120~200m | L/17 ~ L/20 | L/38 ~ L/50 |

## 节段方案

| 项 | 取值 |
|---|---|
| 每 T 构节段对数 | 主跨 60~80m:6~8 对;80~150m:8~12 对;更大跨径更多,以模板为准 |
| 节段长度 | 3.5~5m |
| 0 号块 | 墩中心两侧各 5~8m |
| 合龙段 | 2m |

## 其余方案默认值

以复制来的模板为准;从零写或用户没给时用下表。

| 项 | 默认 |
|---|---|
| 材料 | 主梁 C55~C60;桥墩 C50~C55;钢绞线 Strand1860 |
| 单元组 | 每个节段一组(`0号块单元`、`1号块单元`…)、边跨/中跨合龙段、边跨现浇段、桥墩、桥台弹簧;车道参照组 `主梁单元` |
| 钢束投影组 | 每根钢束一组,`<钢束名>Gp` 或 `<钢束名>_CurveGp`,以模板为准 |
| 主墩 | **不设支座**:墩顶与主梁用主从约束固结(`墩梁固结`),墩底固定(`墩底固定点`),从 CS1 起就激活 |
| 桥台 | 每个桥台两组支座(一侧横向固定、一侧横向放开),纵向都放开 |
| 临时约束 | 边跨现浇段临时支架 |
| 荷载 | 各节段自重、挂篮与湿重、合龙吊架荷载各自成工况;二期 = 铺装 + 护栏;沉降:桥墩 15mm、桥台 10mm |
| 活载 | 左偏 / 中载 / 右偏 3 个车道工况;冲击系数用 `CUSTOM` + 基频,数值看项目画像 |

## 施工阶段

```
CS1        下部及 0 号段(28d)
CS2~       1~N 号段,每段三个阶段:挂篮 1d → 浇筑 8d → 张拉 1d
之后       边跨支架现浇(12d)
           边跨合龙(12d)  激活桥台支座,钝化边跨临时支架
           中跨合龙(12d)
           二期恒载(60d)
           徐变十年(3650d)
           运营阶段(0d)
```

## 钢束

分类(T / F / ZB / ZT / BB / BT)、每阶段块一个预应力工况、底板束贴底、边跨底板束端部定位都与悬浇梁相同,见 `osis-bridge-cantilever-box` §钢束;钢束优化也按那里的分区和表做。刚构节段多,每类条数以模板 `_8` 为准。

缩短或平移贴底束(BB、ZB)时,锚端 z 保持距梁底的原高度,并按新 x 处的梁高核净空 ≥ 0.11m;其余规则见 `osis-module-tendon` §贴底束 bottom() 机制。
