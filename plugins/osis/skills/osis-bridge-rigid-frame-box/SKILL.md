# osis-bridge-rigid-frame-box

> 章节顺序与 `_0`~`_10` 模块对齐,按"截面 → 节点 → 单元 → 边界 → 荷载 → 钢束 → 活载 → 阶段"顺序对应写 `prep/_N.py`。

> 变截面悬浇梁(非刚构)走 `osis-bridge-cantilever-box`,不在本 SKILL 范围。

## 必问参数 (question 工具)

用户提示缺这些参数时,打包成一个 question 调用一次问完。options 用本 SKILL 表格里的标准值,第一项为推荐默认。

| 参数 | 选项(第一项为推荐) | 何时可省 |
|---|---|---|
| 跨径组合(主跨 L) | 模板现有双肢 `65+120+65` / `84+156+84` / `86+160+86` / `90+170+90` / `95+180+95` / `102+190+102` / `108+200+108` / **七跨** `56+5x100+56`、单肢 `95+95`;用户跨径接近某项时推荐并标注「有现成模板可直接复制」 | 用户没提跨径时必问 |
| 桥宽 | `16.75m`、`12.75m`、`12.775m`、`10.75m`、`9.5m`、`其他` | 模板里没有等宽时必问 |
| 桥墩形式 | `双肢薄壁墩`、`单肢实心墩` | 用户没提桥墩时必问 |
| 主梁材料 | `C60`、`C55`、`C50` | 跨径 ≥ 80m 默认 C60,小跨径问 |
| 截面形式 | `单箱单室`、`单箱双室` | 跨径 ≤ 80m 默认单箱单室;>120m 必问 |
| 节段对数(每 T 构) | 模板默认(主跨 60~80m 取 6~8,80~150m 取 8~12,**刚构可到 15**) | 没提节段方案时问 |

## 材料 (→ prep/_3_material.py, osis-module-material)

| 部位 | 推荐 | 规范 |
|---|---|---|
| 主梁 | C55~C60 | JTG3362_2018 |
| 桥墩 | C50~C55(高墩可达 C60) | JTG3362_2018 |

## 截面 (→ prep/_4_section.py, osis-module-section)

### 截面方案

- 单箱单室或单箱双室
- 变截面:跨中恒高段 + 边跨现浇段 + 桥墩 + 悬浇渐变段 + 0 号块
- 梁高只在**变化段**用抛物线,与构造评分 D3 同一套坐标(详见 `references/section_parabola.md`):
  `h(x) = h_mid + (h_root - h_mid) * (1 - x/L)^n`
  - `x`:距 **0 号块外缘**。0 号块内 `h = h_root`;合龙/跨中平台 `h = h_mid`
  - `L`:变化段长度 = 半主跨 − 合龙段半长 − 0 号块半宽(**不是**距墩中心;刚构 0 号块更长,此项更关键)
  - `n`:按主跨取,见下表;**不要默认 2**。改 n 必须按桩号重算 h,禁止从旧高度开方反推指数

| 主跨 | 取 n |
|---|---|
| [70, 120) m | 1.8 或 2.0 |
| [120, 150] m | 1.8 |
| (150, 250] m | 1.5 |

- 梁高经验值:刚构 h_root 较悬浇梁加深 5~10%(主墩无永久支座,受力大),h_mid 取值接近悬浇梁

| 主跨 L | 桥墩 h_root | 跨中 h_mid |
|---|---|---|
| 30~50m | L/14 ~ L/17 | L/28 ~ L/35 |
| 60~80m | L/15 ~ L/17 | L/30 ~ L/38 |
| 80~120m | L/16 ~ L/19 | L/35 ~ L/45 |
| 120~200m | L/17 ~ L/20 | L/38 ~ L/50 |

- 截面数量 ≈ 跨中(1) + 桥墩(1) + 边跨现浇段(1) + 悬浇渐变段(N) + 0 号块(2~3)

### 节段方案

- 每个 T 构节段对数:主跨 60~80m 取 6~8 对,80~150m 取 8~12 对,**刚构可到 15 对**
- 节段长度:3.5~5m
- 0 号块长度:桥墩中心两侧各 5~8m(刚构 0 号块更长)
- 合龙段长度:典型 2m

### 桥墩/桥台

- 双肢薄壁墩(2 柱)或单肢实心墩,**无永久支座**,主梁与桥墩固结
- 桥台:锚固端,桥台节点 z 偏置

## 节点 (→ prep/_5_node.py, osis-module-node)

主梁节点沿 y=0、z=0 轴线,按**节段端点 + 锚固点 + 0 号块边界 + 合龙段端点**布置。

桥墩节点:

- 双肢墩 y 偏置更大(由桥宽决定),z = -h
- 刚构墩底节点 z 更深(依墩高)

## 单元 (→ prep/_6_element.py, osis-module-element)

### 构件组(语义)

- **节段组**:每个节段独立成组(0号块/1号块/2号块/.../N号块)
- **合龙段组**:边跨合龙段 + 中跨合龙段
- **现浇段组**:边跨支架现浇段(如有)
- **刚构墩组**:刚构桥墩(无永久支座,通过固结表达)

### 钢束投影组

按"钢束名 + CurveGp/Gp"约定,**具体组名格式由 `osis-module-element` 定义**。

### 车道引用组

`主梁单元`:包含全部主梁单元,供 `_9_analysis` 引用车道。

## 边界 (→ prep/_7_boundary.py, osis-module-boundary)

### 刚构支座方案

| 部位 | 永久约束 | 临时约束 |
|---|---|---|
| 桥墩 | **墩梁固结**(主从约束) | 临时锚固(合龙前) |
| 桥台 | 横固纵释 + 横释纵释 两组 | 无 |

**刚构无永久支座**,主梁与桥墩固结成为超静定结构。

### 体系转换时序

- 边跨合龙阶段:激活边跨合龙段 + 部分桥墩固结
- 中跨合龙阶段:激活中跨合龙段 + 解除桥墩临时锚固(转为永久固结)

## 荷载 (→ prep/_8_loadcase.py, osis-module-loadcase)

### 自重与二期

- **自重**:主梁/桥墩/合龙段 单独自重工况
- **二期恒载**:铺装 + 防撞护栏(左右半幅分别施加)

### 温度

- 整体升温 +20℃、整体降温 -20℃(所有单元)
- 正温度梯度、负温度梯度(按规范 T 型)

### 沉降

- 桥墩:10~15mm
- 桥台:10mm

## 钢束 (→ prep/_8_loadcase.py, osis-module-tendon)

### 分组(6 类)

钢束体系与悬浇梁相同,按类别命名:

| 类别 | 含义 |
|---|---|
| BB | 边跨底板束 |
| BT | 边跨顶板束 |
| F | 腹板束 |
| T | 顶板束 |
| ZB | 中跨底板束 |
| ZT | 中跨顶板束 |

刚构节段更多,钢束数量更多;每类条数以所选刚构模板 `_8` 为准。

### 张拉方案

- **两端张拉**(`tension_type="BOTH"`)
- **张拉控制应力**:1.395e9 Pa(1395MPa)
- **控制方式**:`tension_force_type="ST"`(力控制)
- **孔道参数**:μ=0.17, k=0.0015/m, 锚具变形 6mm/6mm, 松弛 0.3

### 钢束约束

- 控制点 x 必须在 element_group 覆盖范围内
- **贴底束(BB/ZB)= `bottom()` 贴底 + 锚端字面 z**:竖曲线 4 行 = 锚端(字面 z)→ 快速下弯行(bottom 行)→ 贴底终点(bottom 行)→ 上弯锚端(字面 z),行数、行序保持。缩短/平移:保行结构和 bottom 行号,贴底行只动 x 不改 z,锚端 z 保持距梁底原高度并核净空 ≥0.11m。机制、BottomTS 挂模型不挂文件、出梁排查顺序见 `osis-module-tendon` §贴底束 bottom() 机制
- 钢束张拉阶段晚于构件激活阶段
- 跨中合龙前,中跨钢束未张拉
- **预应力工况名是 `_8` 与 `_10` 的契约**:每个阶段块的预应力工况在 `_8` 的 `load.create(<名>, "CS", ...)` 创建,`_10` 的 `define_loadcase(..., <名>)` 逐字引用,不得改写;钢束 shape 名只出现在 `_8` 的 `create("PST", ...)` 里,不出现在 `_10`

### 边跨底板束端部定位

- 左边跨底板束**起点**距梁端 0.2m
- 右边跨底板束**终点**距梁端 0.2m

## 活载 (→ prep/_9_analysis.py, osis-module-analysis)

- **移动荷载标准**:`JTGD60_2015,HIGHWAY_I`
- **车道**:3 个工况(左偏 / 中载 / 右偏),车道长度取中跨满跨
- **横向折减系数**(固定):`[1.2, 1.0, 0.78, 0.67, 0.6, 0.55, 0.52, 0.5, 0.5, 0.5]`
- **冲击系数 μ**:跨径/梁型相关,数值看项目画像
- **沉降**:桥墩 + 桥台

## 施工阶段 (→ prep/_10_stage.py, osis-module-stage)

### 施工方法

- 0 号块:临时托架现浇
- 1~N 号块:挂篮悬浇,每节段"挂篮 → 浇筑 → 张拉"三步
- 边跨合龙段:支架现浇
- 中跨合龙段:吊架合龙
- 节段比悬浇梁多,合龙时序更复杂

### 阶段序列轮廓

```
CS1        下部及 0 号段(30~60d,刚构更长)
CS2~CSxn   1~n 号段 × (挂篮 1d + 浇筑 8d + 张拉 1d)
CSn+1      边跨合龙
CSn+2      中跨合龙
CSn+3      解除桥墩临时锚固 → 永久固结
...
```

具体节段长度、阶段数参考 `references/templates/变截面连续刚构-*/`。

## 模板与代码生成

### 模板枚举(接到本桥型建桥任务第一件事)

1. `ls references/templates/`(**平铺子目录**,没有 `<桥型>/<跨径>` 两级)
2. **向用户显式报告** `共 N 个模板: [完整目录名, ...]`。名单像被截断 → 再 ls
3. **禁止**未列出全量就宣布「最近模板是 xxx」
4. 跨径+桥宽+单/双肢+截面形式已命中时,幂次 n / 材料 / 节段数不同只算近似命中(复制后按 `section_parabola.md` 重算变化段 h),**不要改用另一跨径**

例:用户要的跨径、桥墩形式、桥宽都与某模板一致,只有 n 不同 → 命中该模板,复制后只改梁高,禁止换成另一跨径的「最近」模板。

### 模板位置与布局

目录树、builder 名、入口见总控 `osis-engine/references/template_layout.md`。本桥模板在 `references/templates/`(平铺)。

### 匹配规则

在 §模板枚举 报出全量之后,按**桥墩形式(单肢/双肢) → 跨径**两级匹配。覆盖单肢和双肢两种工艺。

### 跨径 fallback 规则

**仅当全量清单里没有同跨径组合时**才允许用跨径最接近或最大的模板作基础。未 ls 报全量不得 fallback。**严禁**对截面、预应力钢束采用等比例缩放。截面保持原模板不变,仅调整节点位置;钢束应从跨中直线段截去相应长度减短,曲线段几何不变。
