# 阶段序列模式参考

> 各桥型阶段序列轮廓参考。本文件是 `osis-module-stage` 的补充。

## 通用模式

阶段序列由桥型层 SKILL 决定,本模块只负责按方案建阶段。常见模式:

### 简支体系(预制简支)

```
CS1 预制张拉(7d)
CS2 存梁(60d)
CS3 二期恒载(30d)
CS4 徐变十年(3650d)
CS5 运营(0d)
```

### 简支转连续体系

```
CS1 预制张拉(7d)
CS2 存梁(60d)
CS3 墩顶现浇+负弯矩束(7d)
CS4 体系转换(10d)  ★ 关键节点
CS5 二期恒载(30d)
CS6 徐变十年(3650d)
CS7 运营(0d)
```

### 悬浇体系(普通悬浇梁)

```
CS1       下部及 0 号段(28d)
CS2~CSxn  1~n 号段 × (挂篮 1d + 浇筑 8d + 张拉 1d)
CSxn+1    边跨支架现浇(12d)
CSxn+2    边跨合龙(12d)        ★ 体系转换
CSxn+3    中跨合龙(12d)
CSxn+4    二期恒载(60d)
CSxn+5    徐变十年(3650d)
CSxn+6    运营(0d)
```

### 悬浇刚构体系

阶段数 50+。详见对应桥型 SKILL 的"施工方法与阶段"节。

## 体系转换的关键模式

**核心原则**:体系转换阶段必须**一次性完成**所有激活/钝化,分阶段做会导致结构不收敛或机构。

典型激活/钝化清单:

- 激活:永久支座、桥墩弹簧、永久固结(刚构)
- 钝化:临时支座、临时支架、临时锚固

**简支变连续**的 CS4 体系转换:
- 激活:中墩永久支座
- 钝化:中墩临时支座

**悬浇**的边跨合龙体系转换(CSxn+2):
- 激活:4 组永久支座(横固/横释/纵固/纵释)× 2 桥台 + 4 组桥墩弹簧
- 钝化:4 组临时支架(2 桥墩 + 2 边跨)

**悬浇**的中跨合龙(CSxn+3):
- 激活:中跨合龙段
- 钝化:桥墩临时纵向约束(合龙后释放)

## 命名约定

阶段名用 `CS{n}_{动作}` 格式:`CS1_xxx`、`CS27_xxx`(具体动作由桥型层给)。

## nBirth 规则

```python
stg.define_element(bActive, bInc, '组名', nBirth=N, ePart=0)
```

- `nBirth=0.0`: 弹性连接(`create_spring`)
- `nBirth=7.0`: 混凝土单元(预制/现浇)的张拉龄期
- nBirth 设错会报"弹性连接报错"或激活时间错
