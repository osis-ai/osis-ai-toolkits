# osis-bridge-conventional-box

> 模板在 `references/templates/`,命中就复制(流程见 `osis-engine` §模板优先策略)。本文件写怎么选模板和改模板、本桥型的方案默认值。API 写法在各 `osis-module-*`。

## 必问参数

| 参数 | 选项(第一项为推荐) | 何时问 |
|---|---|---|
| 跨径组合 | 模板清单里最接近的一项(20~60m,单跨到三跨) | 没提跨径 |
| 桥宽 | 模板现有 `9` / `10.5` / `12.25` / `12.75` / `13` / `13.25` / `16.5` / `16.7` / `16.75` / `17.13` / `20.7` m,变宽 `16.75~17.77`、`23~18.45` | 模板里没有同宽 |
| 截面形式 | `单箱单室`、`单箱双室`、`单箱三室`、`单箱四室` | 桥宽 > 12m |
| 梁高变化 | `等截面`、`变截面` | 跨径 > 40m,或主跨比相邻跨大 1.5 倍以上 |
| 张拉方式 | `两端张拉`、`单端张拉` | 用户提到匝道时(A/D 匝道模板各有两端、单端两版,目录名带「单端张拉」) |

钢束分组、张拉参数不主动问,用户指定才改。

## 模板

模板名 `现浇[变宽]<等/变>截面箱梁-<跨径组合>-<室数>-<桥宽>[-备注]`。按**截面室数 → 等/变截面 → 跨径组合和桥宽**匹配。

| 情况 | 做法 |
|---|---|
| 跨径、桥宽、室数、等/变截面都一致 | 复制后直接跑 |
| 室数相同,跨径或桥宽不同 | 复制最近的模板,只改差异:跨径按下面的规程;桥宽改 `_4` 的截面尺寸并重算构件理论厚度(`osis-module-element` §构件理论厚度) |
| 室数不同,模板里没有 | 从零写 `_1`~`_10` |

复制后只改差异,不审查、不"改进"模板的其余部分。

**各模板的命名不统一,不要统一改名,也不要假设名字**:主梁单元组有的叫 `全部`、有的叫 `全桥`、`结构组_1`;车道参照组是 `1_车道线单元组` 这类;钢束有 `B1`~`B3`、`F1`~`F4`、`1_`~`3_`;边界组有 `成桥`、`零时`(临时支承)、`弹性连接`、`刚性连接`;工况名是 `预应力_预应力`、`二期_二期` 这类。写 `_8`/`_9`/`_10` 时名字从复制来的 `_6`/`_7`/`_8` 里取。

### 改跨径

**不要等比例缩放**截面、梁高、钢束和节点。支座所在的节点号和约束不改。

| 文件 | 等截面 | 变截面 |
|---|---|---|
| `_5` 节点 | 跨长变化量只进跨中均布段;梁端和支点附近的节点间距不变 | 渐变段节点按原来的相对位置重排,支点两侧的布置不变 |
| `_6` 单元 | 跟着节点 | 跟着节点 |
| `_4` 截面 | 不动 | 跨径换档时按分档表重选梁高,渐变规律保留 |
| `_2` 钢束曲线 | 直线段增减长度;起弯点、半径、过渡段不变 | 起弯点跟着支点和跨中走;曲线几何不变 |
| `_7`、`_9` | 不动(车道长度按新跨径改) | 同左 |
| `_10` 阶段 | 不动 | 不动 |

改完核对:梁高和截面没有被整体缩放;梁端加密段左右对称,没有碎单元;钢束都在梁内。

## 方案默认值

以复制来的模板为准;从零写或用户没给时用下表。

| 截面室数 | 模板跨径范围 | 梁高 h | 顶板半宽 | 备注 |
|---|---|---|---|---|
| 单箱单室 | 25+25m | 2.2m | 桥宽 9m | 等截面 |
| 单箱双室 | 20+30+20 ~ 42+47+42m | 1.5~2.0m | 5.25~6.375m(桥宽 10.5~13.25m) | 等截面 |
| 单箱三室 | 25+25 ~ 40+60+40m | 1.8~2.3m | 6.5~9.2m(桥宽 13~17.8m) | 等截面、变截面 |
| 单箱四室 | 25+25 ~ 30+30m | 1.6~1.8m | 10.35m(桥宽 20.7m) | 等截面 |

| 项 | 默认 |
|---|---|
| 材料 | 主梁 C50;钢绞线 Strand1860 |
| 截面 | `CONVENTIONALBOX`,顶板、底板宽度参数都是**单侧宽**(半宽);变宽桥只靠截面渐变表达,节点仍在 y=0 |
| 节点 | 约 2m 均布 + 梁端加密(从距梁端约 0.08m 起) |
| 荷载 | 一次落架自重(`z_coeff=-1.04`)、横梁或横隔板的节点集中力、二期、整体升降温、正负温度梯度 |
| 张拉 | 主线两端张拉;匝道单端张拉版用 `"END"` |
| 活载 | 车道按桥宽布置,每条车道一个参照单元组;冲击系数用 `CUSTOM` + 基频,有实算基频用实算值 |

## 施工阶段

支架现浇,一次落架,**没有体系转换**:

```
一次落架(60d)   激活全部主梁单元、成桥边界、自重、横梁荷载、预应力
二期(30d)       二期恒载
成桥(3650d)     收缩徐变
运营(0d)        整体升降温、温度梯度、沉降、活载
```

大跨变截面模板(40+60+40)是 6 个阶段:支架现浇(临时支承 `零时`)→ 预应力张拉 → 换成成桥边界、撤临时支承 → 二期 → 3650 天 → 运营。阶段名和时长照模板,不统一改写。
