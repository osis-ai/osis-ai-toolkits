# osis-bridge-conventional-box

> 章节顺序与 `_0`~`_10` 模块对齐,按"截面 → 节点 → 单元 → 边界 → 荷载 → 钢束 → 活载 → 阶段"顺序对应写 `prep/_N.py`。

## 必问参数 (question 工具)

用户提示缺这些参数时,打包成一个 question 调用一次问完。**options 第一项(推荐默认)锚定模板库:给用户说的参数找最接近的模板,推荐该模板的参数组合并标注「有现成模板可直接复制,最快」**;用户自报值保留为次选项(走复制+小修)。选定模板参数 → 后续直接复制优先,求快闭环(osis-engine §会话硬约束 · 默认求快)。

| 参数 | 选项(第一项为推荐) | 何时可省 |
|---|---|---|
| 跨径 | 见模板枚举(~20m~60m,2~3 跨组合,含变异跨径),用户跨径接近某模板时推荐该项 | 用户没提跨径时必问 |
| 桥宽 | `9m`、`10.5m`、`12.25m`、`12.75m`、`13m`、`13.25m`、`16.5m`、`16.75m`、`17.13m`、`20.7m`、`23~18.45m(变宽)`,其他按项目给定 | 模板里没有等宽时必问 |
| 截面形式 | `单箱单室`、`单箱双室`、`单箱三室`、`单箱四室` | 桥宽 > 12m 必问 |
| 梁高变化 | `等截面连续梁`、`变截面连续梁` | 跨径 > 40m 或主跨比相邻跨大 1.5x 时必问 |
| 用途 | `主线桥`、`A匝道`、`D匝道` 等 | 用户明确提到匝道时必问 |
| 张拉方式 | `两端张拉`、`单端张拉` | 主线默认两端;A/D 匝道模板各有两端、单端两版(目录名带「单端张拉」) |

> 钢束分组(B1~B3/F1~F4 等)、张拉参数用本 SKILL §钢束 默认值,**不主动问**;用户明确指定才覆盖。

## 模板与代码生成

### 模板枚举(接到本桥型建桥任务第一件事)

1. 完整列出候选:`ls references/templates/` → **显式报告** `共 N 个模板: [a, b, c, ...]`(如不确定结果完整,重新 `ls`)
2. **禁止**未报全量就凭记忆宣布最近模板
3. 按顺序匹配:**截面形式**(单箱几室)→ **梁高变化**(等 / 变)→ **跨径组合 + 桥宽**

### 直接复制优先

总控 §模板优先策略 在本桥型的落地。命中模板时直接复制,不自行构思:

| 档 | 触发条件 | 动作 |
|---|---|---|
| **精确命中** | 跨径组合 + 桥宽 + 截面形式 + 梁高变化与某模板一致(未给的取模板默认) | 按总控 §模板优先策略整套复制(`seedtpl` 优先,本地未命中再 WeKnora),代码 0 改动;`项目画像.md` 一并落地,核对一遍 |
| **近似命中**(默认) | 截面形式相同,跨径/桥宽/等变截面近邻 | 先完整复制,再只改差异处:跨径不同按 §跨径调整规则(`_5`/`_6` 必改,`_4`/`_8`/`_10` 见分模块表,`_7`/`_9` 不动);桥宽不同改 `_4` 截面尺寸 |
| **从零建模** | 截面室数不同(截面族整体变化),或桥型无模板 | `_1`..`_10` 全量生成 |

- 复制路径**不逐项执行 §必问参数**:模板内嵌参数即默认值,完工报告列出假设清单请用户确认
- 复制后只改差异处,不审查、不改进模板其余部分

### 模板位置与布局

目录树、builder 名、入口见总控 `osis-engine/references/template_layout.md`。本桥模板在 `references/templates/`(平铺)。

### 跨径调整规则(现浇箱梁专用)

#### 1. 适用范围

本规则适用于现浇等截面/变截面连续梁的跨径模板适配。

#### 2. 核心总则(强制)

- **禁止**等比例缩放截面/预应力钢束/梁高/梁长,所有调整按模块独立处理
- **支点(支座)位置固定不变**,不得修改

#### 3. 分模块调整

| 模块 | 等截面 | 变截面 |
|---|---|---|
| `_5` 节点 | 跨中标准段截短梁长,梁端/支点附近节点间距不变 | 节段端点重排(渐变段比例保留),支点/合龙段边界不变 |
| `_6` 单元 | 跟着节点改 | 跟着节点改 |
| `_4` 截面 | **完全保留**原模板截面几何 | 若跨径跨档,按跨径分档表重选 `h_root`/`h_mid`;截面 TRANSITION 渐变曲线保留相同相对位置 |
| `_8` 钢束 | 直线段截短,曲线段(起弯+半径+过渡)几何不变 | 钢束按目标跨径重画起弯点;曲线几何不变 |
| `_10` 阶段 | 4/6 阶段序列不变,只调时长 | 阶段序列不变,只调时长 |

#### 4. 最终校验

- 梁高、截面**无整体缩放**
- 支点位置**与原模板一致**
- 等截面:**仅跨中标准段**完成长度适配;变截面:**渐变节点位置重排,几何约束不变**

## 截面 (→ prep/_4_section.py, osis-module-section)

### 截面方案

- **类型**:`CONVENTIONALBOX`(常规箱形截面),每截面一次 `engine.section.create(n, name, "CONVENTIONALBOX", h, bt_l, bt_r, ...)`(bt_l/bt_r = 左/右顶板半宽)
- **等截面**:标准截面 + 过渡渐变截面
- **变截面**:起始 + 终止 + 中间渐变段截面;渐变段 1~3m 一个截面
- **桥墩截面**(仅大跨径):独立 `RECT` 截面(矩形墩),编号不与主梁截面重叠

### 跨径分档(梁高 / 顶宽)

| 截面室数 | 跨径范围 | 典型梁高 h | 顶板半宽 bt_l | 说明 |
|---|---|---|---|---|
| 单箱单室 | 25+25m | 2.2m | 8.375m(约 9m 桥宽) | 等截面 |
| 单箱双室 | 20+30+20~42+47+42m | 1.5~2.0m | 5.25~6.375m(约 10.5~13.25m 桥宽) | 等/变截面 |
| 单箱三室 | 25+40+30~40+60+40m | 1.8~2.3m | 6.5~9.2125m(约 13~17.8m 桥宽) | 等/变截面 |
| 单箱四室 | 25+25~30+30m | 1.6~1.8m | 10.35m(约 20.7m 桥宽) | 等截面 |

> 上表为现有模板的取值范围,桥宽 ≈ bt_l + bt_r;以所选模板 `_4` 为准。具体截面几何(腹板厚度/底板厚度/悬挑/翼缘尺寸…)看 `prep/_4_section.py` 的 CONVENTIONALBOX 参数列表。

## 节点 (→ prep/_5_node.py, osis-module-node)

主梁节点沿 y=0、z=0 轴线布置:

- **等截面**:节点间距均布(~2m) + 梁端加密(从 ~0.08m 起,0.5~0.3m 间距)
- **变截面**:节段端点 + 0 号块边界 + 合龙段端点;节点间距随渐变段逐渐加密(梁高变化较大的段落)
- **变桥宽**:桥宽变化仅通过截面渐变表达,节点仍在 y=0 轴线上
- 节点数 ≈ 单元数 + 1,桥长 = last_x ≈ 跨径总和 − 0.04~0.08m(梁端 0.08m 锚固缩进)

## 边界 (→ prep/_7_boundary.py, osis-module-boundary)

### 支座方案

现浇箱梁**无体系转换**,边界全程固定:

| 边界组 | 类型 | 作用 |
|---|---|---|
| `一般支撑` | GENERAL | 中墩/桥台永久支座(部分模板单组,部分模板中墩+桥台分别分组) |
| `弹性连接` | ELASTIC | 桥墩弹性约束(弹簧刚度见 `_7_boundary.py`) |
| `刚性连接` | RIGID | 部分等截面模板桥台**刚性约束**(等效固结) |
| `成桥` | GENERAL + 弹性 | 等截面匝道模板全部成桥约束(两组,无单独弹性连接) |
| `零时` | 临时约束 | 大跨径模板临时支架(成桥阶段后钝化) |

各模板边界组具体名称由 `.out` 决定,模板间有几套命名约定,不能假设任意模板用同一套。**新建模板时从 `.out` 解析,不改动命名**。

## 荷载 (→ prep/_8_loadcase.py, osis-module-loadcase)

### 自重与二期

- **自重/一次落架自重**:整跨一步激活(CS "自重"),`create("GRAVITY", 0, 0, -1.04)`(-1.04 是乘 g 的系数,负=向下)
- **二期恒载**:铺装工况(CS "二期",20d 施工期)
- **横梁/横隔板**:节点集中力(等截面用"横梁_横梁"或"横隔板_横隔板",变截面多并入二期)
- **支架现浇自重**(仅大跨径 6 阶段模板):CS 前期单独激活,含支架 + 模板自重

### 温度

- 整体升温 +20℃ / 整体降温 -20℃(运营阶段激活)
- 正温度梯度 / 负温度梯度(运营阶段,按规范 T 型混凝土箱梁)

## 钢束 (→ prep/_8_loadcase.py, osis-module-tendon)

### 分组与命名

| 模板类型 | 钢束名 | 张拉方式 | 数量 |
|---|---|---|---|
| 等截面(单箱单室~双室) | `B1`~`B3` | 两端张拉(BOTH,部分匝道单端) | 2~3 束 |
| 变截面(单箱双室~四室) | `F1`~`F4` | 两端张拉(BOTH) | 3~4 束 |
| 大跨径 | `1_`~`3_` | 两端张拉(BOTH) | 3 束 |

具体命名格式由 `.out` 决定,**新建模板时保留原命名,不统一改**。

### 张拉方案

- **两端张拉**(`tension_type="BOTH"`),`tension_force_type="ST"`(力控制)
- **张拉控制应力**:1.395e9 Pa(1395MPa,典型 0.75 × 1860MPa)
- 钢束投影组名由 `osis-module-element` 决定(自动生成,不手工指定)

## 活载 (→ prep/_9_analysis.py, osis-module-analysis)

- **移动荷载标准**:`JTGD60_2015,HIGHWAY_I`
- **车道**:1 条(中线),车道长度取略小于跨径
- **横向折减系数**(固定):`[1.2, 1.0, 0.78, 0.67, 0.6, 0.55, 0.52, 0.5, 0.5, 0.5]`
- **冲击系数 μ**:`include(..., "CUSTOM", f)` 的 f 是结构基频(Hz),按规范由 f 算 μ;模板值见 `_9`,有实算基频用实算值
- **沉降**:运营阶段 SETL 支座沉降(部分模板)
- **模态**:运营阶段 MODAL(振型分析,部分等截面模板)

## 施工阶段 (→ prep/_10_stage.py, osis-module-stage)

### 施工方法

满堂支架一次性浇筑 → 张拉正弯矩束 → 桥面铺装 → 徐变 → 运营。无预制桥型的存梁 + 架设阶段,无体系转换。

### 阶段序列(4 阶段,典型)

```
CS1  自重(30d) — 激活主梁单元 + 弹性连接 + 一般支撑 + 自重 + 预应力
CS2  二期(20d) — 激活二期恒载
CS3  成桥(3650d) — 收缩徐变长期效应
CS4  运营(0d)  — 整体升降温 + 正负温度梯度 + 移动荷载 + 沉降 + 模态
```

### 阶段序列(6 阶段,大跨径含支架现浇)

```
CS1  支架现浇自重(28d) — 激活结构组 + 支承 + 零时边界 + 支架自重
CS2  自重(30d)           — 激活自重 + 预应力
CS3  二期(30d)           — 激活二期
CS4  升温(0d)            — 整体升温
CS5  成桥(3650d)         — 收缩徐变
CS6  运营(0d)            — 梯度升温/降温 + 沉降 + 移动荷载
```

- 各阶段时长按模板原值,**不用统一强行改写**。跨径变化影响节段数 → 调 CS1 自重时长(±5d),其余不变。
- **无 CS4 体系转换**(本桥型关键区别),不需要激活/钝化临时支座。
