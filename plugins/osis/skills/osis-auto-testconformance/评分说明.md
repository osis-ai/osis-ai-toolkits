# 评分说明(构造评分 + 受力评分)

本 skill 出两套分，各出各的总分，不合并：**构造评分**(一~九节，`scripts/model_conformance/`，不求解)评尺寸和布置；**受力评分**(第十节，`scripts/test_mechanics.py`，要求解)评内力、反力、挠度、应力。本文说明各自评什么、不评什么、各项怎么扣分。数值以代码为准，改规则时同步改这里。两套分的维度都叫 D1、D2……，引用时带上"构造"或"受力"。

## 一、评价方式

1. **评的是 OSIS 里的模型**。脚本把当前实例的模型 `export_apdl` 导出成求解器命令流，用 pyosis 的 `transfer` 转回模板结构的 prep 代码(临时目录)，再从 `_4_section`、`_5_node`、`_6_element`、`_7_boundary`、`_8_loadcase`、`_10_stage` 等文件里读出被评的量。代码原来怎么写不影响结果。没有 OSIS 时可用 `--candidate-dir` 直接读工程代码，只有代码和模型一致时才可信。
2. **桥型和是否连续由调用方传入**(`--bridge-type`、`--is-continuous`)，按桥型选一套规则。不传时按工程名猜，猜不中按 `unknown` 处理。
3. **被评的量从模型里提取**:

| 量 | 取法 |
|---|---|
| 主跨 L | 由支座 / 墩节点桩号还原各跨，取最大跨；刚构优先取墩间距；都没有时退回联长。`--expected-L` 只在提取不到时兜底 |
| 支点梁高 H_root / 跨中梁高 H_mid | 主梁截面梁高的最大值 / 最小值 |
| 顶 / 底 / 腹板厚 | 取与 H_mid、H_root 同一截面的值；悬浇 / 刚构的根部，在 0 号段等高平台内取底板最小值作支点附近底板，取最大值作横梁底板 |
| 梁高曲线指数 n_H | 沿桥纵向取 (x, h) 剖面，去掉根部和跨中的等高段，在变化段内用 H = H_mid + (H_root − H_mid)·uⁿ 对 n = 1.40~2.50(步长 0.05)逐个比较，取误差(RMSE)最小的 n |
| 梁宽 | T 梁 / 小箱梁 2·bm + 2·bc；空心板 bs。可用 `--beam-width` 覆盖 |
| 混凝土折算厚度(m³/m²) | 按单元长度加权的平均截面面积 ÷ 梁宽；算不出面积时用 `assign_component_thickness` 的均值。可用 `--concrete-ratio` 覆盖 |
| 钢绞线用量(kg/m³) | 有效预应力钢束线密度(kg/m) ÷ 平均截面面积 |
| 是否预应力 | 模型里有没有预应力荷载；可用 `--is-prestressed` 覆盖 |
| 竖向预应力 | 支点两侧 L/3 内有含腹板竖筋(WEBVERTICALREBAR)的截面，或有按竖向命名的预应力钢束 / 工况 |
| 施工阶段 | 阶段个数和阶段名 |
| 零号块长度 | "0号块" 单元组覆盖的梁长，多个墩取偏离 9~14 m 最远的一块 |
| 墩高 | 桥墩单元组(或 RECT / "桥墩" 截面)节点的 z 跨度 |
| 混凝土等级 | 混凝土材料里的最大 C 等级 |

## 二、范围

**评**：构造尺寸和布置是否落在工程经验区间，包括跨径适配、高跨比、截面常规尺寸、经济性指标(折算厚度、钢绞线用量、含筋量)、施工阶段是否齐全。

**不评**：荷载组合与规范验算(用 `osis-check`)、求解结果、钢束线形、普通钢筋配置。规则是经验区间，不是规范条文；超出区间只说明"不常规"，不等于结构不安全。

支持 6 种桥型：悬浇连续梁 `cantilever_box`、连续刚构 `rigid_frame`、简支 T 梁 `t_girder`(含矮 T)、预制小箱梁 `precast_small_box`、现浇箱梁 `cast_in_place_box`、空心板 `hollow_slab`。其他桥型按 `unknown` 处理。

## 三、怎么出分

- 每座桥评 D1~D5 五项，每项 0~1 分；**总分 = 五项加权和，满分 1.0**
- 每项内部从 1 分起扣；有小项的按小项权重加权
- 单项状态：≥ 0.9 符合要求(ok)；≥ 0.5 基本符合(warn)；< 0.5 不符合(fail)
- 总评级：1.0 优秀；≥ 0.8 良好；≥ 0.6 合格；≥ 0.4 待改进；其余不合格
- 总分 < 0.5 时脚本退出码为 1
- 数据缺失时的处理：
  - 多数项提取不到就按不满足扣分
  - 悬浇 / 刚构的 D4、D5 跳过缺失的小项，按剩余权重归一；全部缺失给 1.0
  - n_H 匹配失败给 0.5 中性分
  - RC T 梁跳过马蹄和钢绞线小项

## 十、受力评分

脚本 `scripts/test_mechanics.py`。构造评分只看尺寸，看不出钢束放得对不对、荷载加没加全、阶段接得对不对；受力评分把模型算一遍，用几个结果来判断。

### 评价方式

1. **评的是 OSIS 里的模型的求解结果**。模型的导出方式同构造评分(`export_apdl` → `transfer` → prep 代码)，导出到临时工程 `<工程目录>/_mechanics/model`，在仅求解器模式下重建、求解、读结果。用户的模型、施工阶段和已有结果都不动。
2. **分三档，算的阶段越多，评的维度越多**。缺省快速档。

| 档 | `--tier` | 怎么算 | 评的维度 |
|---|---|---|---|
| 快速档 | `fast`(缺省) | 所有施工阶段压成一个阶段 | D1~D5 |
| 施工阶段档 | `stage` | 保留施工阶段，算到成桥为止；去掉徐变十年和运营阶段 | D1~D7 |
| 完整档 | `full` | 全部阶段原样求解 | D1~D8 |

3. **被评的量从求解结果里提取**:

| 量 | 取法 |
|---|---|
| 成桥阶段 | 第一个"时长 ≥ 1000 天"或"带分析工况(活载 / 沉降等)"的阶段之前的那个阶段。快速档是压成的那一个阶段 |
| 主梁 | 沿桥向的梁单元(两端节点 x 不同，且高差不超过 x 差的 20%)。桥墩、弹簧不算 |
| 恒载、预应力的效应 | 成桥阶段的 `_恒载_<阶段>` 是恒载；`_合计_<阶段>` 减 `_恒载_<阶段>` 是预应力(含收缩徐变等时变效应) |
| 结构自重 | 成桥时还激活的单元：长度 × 两端截面平均面积 × 材料容重，求和。不含二期恒载 |
| 最大跨 | 有竖向反力的节点按桩号排序，相邻间距的最大值 |
| 恒载挠度 | 主梁节点在 `_恒载_<成桥阶段>` 下竖向位移的最大绝对值 |
| 应力 | 主梁单元各截面的最大 / 最小正应力(`sxComp` 的 Max、Min 点)，拉为正 |
| 混凝土等级 | 混凝土材料里的最大 C 等级；主梁不是最高等级时用 `--concrete-grade` 传。fck、ftk 按 JTG 3362-2018 表 3.1.3 |

各档改施工阶段的做法：

- 快速档：回放各施工阶段的激活 / 钝化，得到成桥时还在的单元组、边界组、荷载工况，放进一个阶段。自重工况只留一个(自重作用在"本阶段激活的单元"上，留多个会重复计)。
- 施工阶段档：删掉成桥阶段之后的全部阶段。
- 快速档和施工阶段档都在最后补一个空阶段：OSIS 把最后一个阶段的荷载当独立工况，不计入累计。
- 完整档不改施工阶段。

### 范围

**评**：混凝土等级、预应力够不够、支座有没有脱空、荷载总量对不对、刚度量级对不对、恒载 + 预应力下的应力。

**不评**：活载、温度、沉降的效应，抗弯 / 抗剪承载力，按荷载组合的抗裂与应力验算(用 `osis-check`)。完整档虽然把运营阶段也求解了，读的仍然只是恒载 + 预应力的结果。评分通过只说明"受力上没有大错"，不等于验算能过。

阈值来自规范条文和力学常识，不是拿模板标定的。满分线多数是规范限值或正常范围的边界；0 分线除注明条文的以外是经验取值。

### 怎么出分

- 每项 0~1 分，满分线和 0 分线之间线性插值
- **总分 = 各项最低分，满分 1.0**。和构造评分的加权和不同：受力上一项不过，模型就不能用，别的项再好也补不回来
- 单项状态、总评级、退出码同构造评分：≥ 0.9 符合要求；≥ 0.5 基本符合；< 0.5 不符合。1.0 优秀；≥ 0.8 良好；≥ 0.6 合格；≥ 0.4 待改进；其余不合格。总分 < 0.5 退出码 1，没评成退出码 2
- 维度按档位和模型取，有几项算几项：
  - 非预应力结构(`--is-prestressed false`)不评 D1、D2
  - 估不出结构自重(截面没有面积或材料没有容重)不评 D4；支承只有一个桩号不评 D5
  - 混凝土等级读不到或不在表 3.1.3 里，不评 D6~D8
  - 没有徐变十年阶段的模型，完整档不评 D8

### D1 混凝土等级(三档都评，仅预应力结构)

| 条件 | 得分 |
|---|---|
| ≥ C40 | 1 |
| < C40 | 0 |

依据：JTG 3362-2018 第 3.1.2 条，预应力混凝土构件不应低于 C40。

### D2 预应力平衡度(三档都评，仅预应力结构)

平衡度 = −预应力弯矩 ÷ 恒载弯矩，取主梁上恒载弯矩绝对值最大的截面。

| 平衡度 | 得分 |
|---|---|
| ≥ 0.8 | 1 |
| 0.5 ~ 0.8 | 线性 |
| ≤ 0.5 | 0 |

- 依据：荷载平衡法。全预应力和 A 类构件在恒载下不允许受拉，预应力要抵消掉恒载弯矩的大部分；0.8 给次内力和截面上下缘不对称留了余量，低于 0.5 时恒载下就会受拉。是经验取值，不是条文。
- 钢束漏张、张拉应力或根数偏小、线形放到截面另一侧时，这一项会掉下来。
- 没有上限：预应力配多了这一项查不出，靠 D6、D7 的应力查。
- 快速档压成一个阶段，有体系转换的桥恒载弯矩分布和实际不同，平衡度只是近似值(简支变连续偏大，悬浇偏小约一成)。
- B 类部分预应力构件正常就可能低于 0.8，会被误判。

### D3 支座反力(三档都评)

取成桥阶段 `_合计_` 下各支承节点的竖向反力。

| 条件 | 得分 |
|---|---|
| 没有负反力 | 1 |
| 有节点出现负反力(绝对值超过最大反力的 1%) | 0.5 |
| 竖向反力合计 ≤ 0，或没有反力 | 0 |

依据：普通支座只能受压，恒载 + 预应力下出现负反力就是脱空，或者是相邻节点重复约束形成了力偶。设了拉力支座或压重的桥负反力是有意的，所以记 0.5 而不是 0。

### D4 荷载总量(三档都评)

比值 = 竖向反力合计 ÷ 结构自重。

| 比值 | 得分 |
|---|---|
| 0.95 ~ 2.2 | 1 |
| 0.7 ~ 0.95、2.2 ~ 2.8 | 线性 |
| ≤ 0.7 或 ≥ 2.8 | 0 |

- 依据：反力等于全部恒载，不会小于结构自重。二期恒载(铺装、护栏)加上横隔板、湿接缝，一般是主梁自重的 10%~110%：宽箱梁和大跨悬浇偏低，比值 1.1~1.6；小跨径预制梁(13~16 m T 梁、空心板)二期恒载占比大，比值可到 2.1。上限 2.2 取自 98 个模板的实测最大值 2.08；0.95 给变截面单元的面积估算留了误差。
- 比值小于 1：自重工况没激活、容重没填或单位错。
- 比值过大：二期恒载量级或单位错，或自重重复计。重复计一次会让比值在原来的基础上加约 1，只有小跨径之外的桥才会越过 2.2，所以这一项抓大错，抓不全轻微的重复。快速档自己只留一个自重工况，自重重复计只有施工阶段档和完整档可能出现。

### D5 恒载挠度(三档都评)

挠跨比 = 恒载挠度 ÷ 最大跨。

| 挠跨比 | 得分 |
|---|---|
| 1/20000 ~ 1/250 | 1 |
| 1/250 ~ 1/100、1/100000 ~ 1/20000 | 线性 |
| ≥ 1/100 或 ≤ 1/100000 | 0 |

- 依据：简支梁均布荷载下 δ/L = (5/24)·(σ/E)·(L/h)。恒载弯曲应力 σ 取 5~15 MPa、E 取 3.45×10⁴ MPa、高跨比 1/15~1/25，得 1/2700~1/400；连续梁和固结体系约为简支的 1/5。正常范围是 1/15000~1/400。
- 这一项查的是量级：弹性模量或截面尺寸的单位错了，挠度会差出几十上千倍。规范对恒载挠度没有限值(靠预拱度抵消)；JTG 3362-2018 第 6.5.3 条的 L/600 限的是活载长期挠度，不是这一项。
- 施工阶段档和完整档读到的是各阶段累计的位移，悬臂施工的桥比快速档大。

### D6 成桥应力(施工阶段档、完整档)

取成桥阶段 `_合计_` 下主梁的最大拉应力和最大压应力，分别打分，取低的。

| | 1 分 | 0 分 | 中间 |
|---|---|---|---|
| 拉应力 | ≤ 0 | ≥ 0.7 ftk | 线性 |
| 压应力 | ≤ 0.5 fck | ≥ 0.7 fck | 线性 |

- 拉应力依据：JTG 3362-2018 第 6.3.1 条，A 类构件准永久组合下不得出现拉应力，频遇组合下拉应力不超过 0.7 ftk。这里只有恒载 + 预应力，比准永久组合还小；这时已经受拉，准永久组合必不过；达到 0.7 ftk，频遇组合必不过。
- 压应力依据：第 7.1.5 条，使用阶段受压区混凝土最大压应力不超过 0.5 fck，这个限值是含活载的；恒载 + 预应力下已经超过，加上活载必不过。0.7 fck 是经验取值。
- 这两条都是必要条件：满分不代表加活载后还满足。

### D7 施工阶段应力(施工阶段档、完整档)

取各施工阶段(到成桥为止)`_合计_` 下主梁的最大拉应力和最大压应力，分别打分，取低的。

| | 1 分 | 0 分 | 中间 |
|---|---|---|---|
| 拉应力 | ≤ 1.15 ftk | ≥ 2.0 ftk | 线性 |
| 压应力 | ≤ 0.7 fck | ≥ 0.9 fck | 线性 |

- 依据：JTG 3362-2018 第 7.2.8 条，短暂状况下压应力不超过 0.70 f′ck，拉应力不超过 1.15 f′tk。拉应力在 0.70 f′tk~1.15 f′tk 之间时规范要求按拉应力大小配纵向钢筋(配筋率 0.2%~0.4%)，这一项不查配筋。
- 规范用的是施工时混凝土的实际强度 f′ck、f′tk，脚本用设计等级的强度，偏松。
- 2.0 ftk、0.9 fck 是经验取值。

### D8 长期应力(完整档)

取徐变十年阶段(成桥阶段之后第一个时长 ≥ 1000 天的阶段)`_合计_` 下主梁的最大拉应力和最大压应力。阈值和依据同 D6，时刻从成桥换成徐变十年后：预应力长期损失和徐变引起的应力重分布都发生了，查的是长期的预应力储备够不够。

### 已知局限

- 曲线桥、斜桥上"沿桥向的梁单元 = 主梁"和按 x 桩号取跨径的做法可能不适用。
- 施工阶段不按"施工 → 徐变十年 → 运营"组织的模型，成桥阶段可能认不准。
- 应力取的是整个截面的最大 / 最小正应力，不区分上下缘，也不扣锚固区等局部。
- 规范条文号是按 JTG 3362-2018 写的，改规则时对照原文核一遍。
