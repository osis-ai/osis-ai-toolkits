# osis-edit-hmid

> 已有模型上改 **跨中梁高**。用户给了目标高度就开干,不要反问,不要查 pyosis 源码。改完跑 `prep/main.py` 写回。

## 何时用 / 何时不用

| 用 | 不用(回 `osis-engine`) |
|---|---|
| 「跨中梁高改成 2.0m」「h_mid=2.4」 | 改根部梁高 `h_root`(另案) |
| 「把跨中截面高度调低」 | 改跨径、加节段、加钢束 |
| 悬浇/刚构/现浇箱梁已有 `_4_section.py` | 从零建模 |

## 铁律

1. **只动** `prep/_4_section.py`;桥台 `z` 等于旧 `-h_mid` 时才动 `_5_node.py` 和画像里对应一句。
2. **禁止**改 `_2_property.py` / `_6_element.py` / `_7` / `_8` / `_10`。钢束竖曲线、单元理论厚度本次不重算。
3. **禁止**构造评测。写回用 `prep/main.py`,不要单跑 `_4`/`_5`。
4. 主梁顶缘对齐(`set_offset(..., "Top")`)时,主梁节点 `z=0` **不要动**。
5. `h_root`(0 号段最大梁高)和 RECT 桥墩截面 **不要动**。
6. 用户没说改底板厚 / 腹板厚 → 那些数字原样保留。

## 5 步(按顺序,不要加步)

### 1. 读旧值

打开当前项目 `py/prep/_4_section.py`。

`CONVENTIONALBOX` 的 **第 4 个参数就是梁高 H**(`create(no, name, "CONVENTIONALBOX", H, ...)`)。

- `h_mid_old` = 名称含「跨中」的箱梁截面 H;没有该名则取箱梁最小 H
- `h_root` = 箱梁最大 H(0 号段根部)
- `h_mid_new` = 用户指定值
- 若 `h_mid_new >= h_root`:仍改,完工时提醒「跨中已不低于根部,曲线会变平/反号」

现浇等截面:所有箱梁 H 相同 → 把这些 H 全部改成 `h_mid_new`,跳过步骤 2 的比例缩放。

### 2. 改 `_4_section.py` 里的 H

对每个箱梁截面 H:

| 条件 | 新 H |
|---|---|
| `H == h_mid_old`(跨中、边跨现浇) | `h_mid_new` |
| `H == h_root`(0 号段根部) | 不动 |
| `h_mid_old < H < h_root`(悬浇渐变 / 0 号段过渡) | 按下式 |

```text
t = (H - h_mid_old) / (h_root - h_mid_old)
H_new = h_mid_new + (h_root - h_mid_new) * t
```

这就是原公式 `h(x)=h_mid+(h_root-h_mid)*(1-x/L)^n` 在 n、x、L 不变时的换元,不必反算桩号。`x` 从 0 号块外缘起,`L` 为变化段长度;本换元不依赖这两个定义,只要**不要改 n**。改 n 必须按桩号重算各截面 h,禁止从旧高度开方反推 `(1-x/L)`。

只替换各 `create(...)` 里的 **H 这一个数字**,周围板厚/翼缘参数不要动。

### 3. 桥台节点 z(可选)

`_5_node.py` 里若有节点 `z == -h_mid_old`(容差 1e-6),且不是桥墩(`z != -h_root`),改为 `-h_mid_new`。  
典型:桥台支座 `y≠0` 的那几个点。主梁轴线节点保持 `z=0`。

### 4. 画像

`项目画像.md` 只改「跨中 h_mid」和若改了的「桥台 z」。不要重写整篇。

### 5. 写回

在项目 `py/prep/` 下执行:

```bash
python main.py
```

无 traceback 即写回完成。

- 不要按梁高比去缩放钢束 z、不要改 `_8`
- 不要为「理论厚度变了」去改 `_6`(用户要再改板厚/桥宽时才做)
- 不要加载桥型 SKILL 的整份模板库
- 不用反问(高度已给出)
- 不要单跑 `_4_section.py` / `_5_node.py` 代替 `main.py`
